## Goal

1. **See.** The view check shows every shape's connection points as
   markers (P7-33's overlay path): `tools.connection.points` in Panel
   Modern (View > Visual Aids) and `view.connections` in Panel Classic.
   The check's state is per window, and both ids read and write the
   same state. Connector drags show the points as P7-33 does, whatever
   the check says.
2. **The tool.** `tools.connection.point` arms the Connection Point
   tool from Home > Tools (Panel Modern) and from the Connector Tool
   split button (Panel Classic). With the tool armed and a shape
   selected:
   - Ctrl+click on the shape adds a point at that local position and
     selects it;
   - Ctrl+drag moves the selected point;
   - click selects a point, and Delete removes it.

   The selected point has its own marker style. Esc returns to the
   Pointer Tool.
3. **Point type.** Right-clicking a point with the tool armed opens
   the connection-point menu: Inward, Outward, Inward & Outward
   (`edit.connection_point.*`). Each writes the row's `Type` (0, 1, 2)
   and shows the current one checked.
4. **Glue follows the points.** Every point edit is one undoable edit
   and re-routes the connectors glued to that shape (P7-32's hook):
   - moving a point moves the ends glued to it;
   - deleting a point re-glues its ends dynamically, writing the
     formulas and records as P7-31 stores them;
   - deleting row *k* renumbers the later rows' glue. Records naming
     `Connections.X<k+1>` and up, and their `PAR(PNT(…))` formulas,
     move down by one, so no end changes target.
5. **Inherited points.** An instance whose points come from its master
   copies them into its own `Connection` section on the first edit
   (instance rows win, ADR 0013), with the indices unchanged, so
   existing glue keeps its target.

## Interfaces

```rust
// crates/model/src/connection.rs (write API, ADR 0039 style)

impl Document {
    /// Adds a connection point at the local point and returns its row
    /// index. Copies inherited rows into the shape's own section first.
    pub fn add_connection_point(&mut self, shape: ShapeId, local: Point) -> Result<u32, Error>;

    /// Moves row `ix` to the local point, keeping `Type`, `DirX`,
    /// `DirY` and the row name.
    pub fn move_connection_point(&mut self, shape: ShapeId, ix: u32, local: Point) -> Result<(), Error>;

    /// Deletes row `ix`; later rows move down by one.
    pub fn delete_connection_point(&mut self, shape: ShapeId, ix: u32) -> Result<(), Error>;

    /// Writes row `ix`'s `Type` (0 inward, 1 outward, 2 both).
    pub fn set_connection_point_type(&mut self, shape: ShapeId, ix: u32, kind: u8) -> Result<(), Error>;
}
```

Commands: `connector.point_add` (`shape`, `x`, `y` in local inches),
`connector.point_move` (`shape`, `point`, `x`, `y`),
`connector.point_delete` (`shape`, `point`), and the three
`edit.connection_point.*` (`shape`, `point`). Each applies directly
with its arguments. The glue renumbering of item 4 runs in the
command, in the same edit.
