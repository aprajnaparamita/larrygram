## Goal

- A right-angle connector shows a midpoint handle on each interior
  segment. Dragging one moves the whole segment perpendicular to
  itself and extends or trims its neighbours; the ends stay glued.
- A moved segment is kept across later edits and re-routes; when a
  glued shape moves, the whole path re-routes and the moved segment is
  forgotten (ADR 0084 rule 4). The memory is per connector, per
  segment.
- The routing function supports the three alpha styles: straight,
  right-angle (multi-segment when a moved segment is kept), and curved
  (a smooth spline through the same route points, ADR 0084 rule 5).
  Degenerate cases (zero-length, coincident points) stay panic-free
  and drop no endpoints.

## Interfaces

```rust
// crates/geom/src/routing.rs (extends the existing module)

/// The axis a moved segment slides along.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SegmentAxis {
    /// A vertical segment moves along x.
    X,
    /// A horizontal segment moves along y.
    Y,
}

/// One segment the user moved: its index in the path and its new
/// axis coordinate (page inches).
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct MovedSegment {
    /// The path segment index (0-based, between point i and i + 1).
    pub index: usize,
    /// The axis the segment moves along (`SegmentAxis::Y` for a
    /// horizontal segment, `SegmentAxis::X` for a vertical one).
    pub axis: SegmentAxis,
    /// The new coordinate along `axis`.
    pub value: f64,
}

/// Routes from `start` to `end` keeping the moved segments in place
/// (ADR 0084 rule 4): the moved segments become fixed geometry and the
/// free parts are routed around them with right-angle runs. An empty
/// `moved` slice is exactly today's [`route`]. Result always begins at
/// `start` and ends at `end`; never panics; a moved segment that
/// contradicts the endpoints (e.g. beyond them) is clamped.
pub fn route_with_moved(
    start: Point,
    end: Point,
    moved: &[MovedSegment],
    options: &RouteOptions,
) -> Result<Vec<Point>, Error>;
```

`RouteStyle` gains `Curved` (naming per ADR 0084 rule 5; the stored
cell value belongs to P7-35). `route`/`route_with_moved` emit the
right-angle run and, for `Curved`, the same points as a smooth
spline; the model's geometry rows already carry `NurbsTo`.

```rust
// crates/commands/src/builtins/connector_segments.rs

/// `connector.move_segment`: args `connector` (Visio id), `segment`
/// (path index), `axis` ("x" | "y"), `value` (page inches). One
/// undoable edit; re-routes with [`route_with_moved`] and records the
/// moved segment on the connector (cleared by the next re-route pass
/// after a shape move).
pub(crate) fn run_move_segment(ctx: &mut AppCtx, inv: &Invocation) -> Result<Outcome, CommandError>;
```

The moved-segment memory lives with the connector's session state
(not in the file; the written geometry *is* the moved shape until a
re-route rewrites it).
