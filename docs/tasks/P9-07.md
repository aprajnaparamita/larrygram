## Goal

1. **The eras.** `McpServer::handle`: a request with modern `_meta` is
   served statelessly (version check, `UnsupportedProtocolVersion`
   `-32022` with `data.supported` for an unknown version); `initialize`
   selects the legacy era for the connection (version choice as ADR
   0080 says); `notifications/initialized` and `ping` in the legacy
   era; `server/discover`; anything else `MethodNotFound`.
2. **The tools.** `tools/list` in `TOOLS` order with title,
   description, `input_schema`, `annotations.readOnlyHint`, and in the
   modern era `ttlMs`, `cacheScope` and `resultType`. `tools/call`:
   `tool_call_op` (arguments to the op's params; an unknown tool is
   `-32602`), `backend.call` with `Source::Mcp` semantics (the op does
   not carry a source: the executor uses `Source::Control`; if the
   distinction matters, list it under Open issues for P9-08),
   `tool_result` (structured content plus text, the PNG as image
   content, an error as `isError: true` with `code` and `data`).
3. **`input_schema`.** JSON Schema 2020-12 for each tool's params,
   written out by hand from the params structs (every property typed
   and described, required fields listed, `additionalProperties:
   false`). A test checks each schema against its struct: every struct
   field appears in the schema and every schema property deserializes
   into the struct.
4. **Tests.** Request and response pairs for both eras (discover,
   initialize, list, call, ping, an unknown method, an unknown tool,
   bad arguments, an operation error, an image result) over a fake
   `Backend` returning canned `OpResult` values. Never print to stdout.
