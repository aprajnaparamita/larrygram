## Goal

1. **Shapes.** Shape group, shape and guide-shape records to
   `larrygram_model::Shape` values in the document arena: `visio_id`
   from the shape-id record, names from the name lists the records
   reference, nesting level to `parent`/`children`, and master, line,
   fill and text style references kept as Visio ids (never resolved or
   flattened).
2. **Transforms.** The transform records to the `Xform`, `Xform1D` and
   `TextTransform` cells, with the unit rule of ADR 0070 (lengths in
   inches, angles in radians, flips as booleans).
3. **Geometry.** Every geometry row kind (move, line, arc, elliptical
   arc, spline knots, NURBS, polyline, infinite line) to a `Geometry`
   section row with its cells; the geometry list records set the row
   order and the section's `NoFill`, `NoLine` and `NoShow` cells.
4. **Degrade, never crash.** An unknown record is skipped with a
   warning; a bad value is a `BadValue` warning and the cell stays
   unset (ADR 0071). `Limits::max_shapes` is enforced.
