## Goal

1. **The harness.** Under `crates/vsd-binary/tests/parity/`: run the
   oracle tools on a corpus file as subprocesses, parse `vsd2raw`
   output into a neutral structure and `vsd2xhtml` output for the text,
   and compare both against our `Import` with the normalisation rules
   of ADR 0072 (tolerances, NFC, trailing whitespace).
2. **The report.** Per corpus file: compared fields, matching fields,
   the parity number, and one line per mismatch with
   `place / field / oracle value / our value`. The "not compared" list
   (ADR 0070 drops) is part of the report.
3. **Availability.** Skip with a clear message when the oracle is
   missing; fail when `LARRYGRAM_REQUIRE_ORACLE=1` says otherwise
   (ADR 0010). The normal gate run stays green without the oracle.
4. **Unit tests.** The dump parser and the comparator are tested with
   hand-built dump text and hand-built `Import` values, so the harness
   itself is covered without the oracle.
5. **The census.** List further openly licensed `.vsd` candidates
   (name, source, licence, why useful) in your Result under Open
   issues, for the master to fetch into the manifest. Do not commit
   the files.

## Acceptance criteria
