## Goal

1. **`args.rs`.** `command_info` (from `CommandMeta`, `Command::args`,
   `Command::remote`, `Registry::enabled`), `args_from_json` (the ADR
   0077 conversion, every refusal naming the argument, the caps), and
   a `ui_request_name` arm for `AgentControl`.
2. **`policy.rs`.** `check_command`, `check_read`, `check_write`,
   `check_write_dir` (ADR 0081: canonicalised paths, a new file by its
   parent, roots, the extension list compared case-insensitively,
   overwrite).
3. **`exec.rs`.** `Executor::execute` for every `Op`: handles synced
   first; `Busy` from `Host::busy`; `Discover` from `server_info`;
   `ListCommands` (filter, stubs, paging with the inspect cursor);
   `DescribeCommand`; `Invoke` (activate the document and page through
   `file.activate` and `page.go`, check the command, convert and check
   the arguments, add nothing the caller did not send, dispatch with
   `Source::Control`, build `Invoked`); the inspect ops; `Render`
   (inline base64 or a policy-checked file).
4. **`host.rs`, `backend.rs`.** Already working (P9-01); adjust only if
   the executor needs it, and keep their tests.
5. **Tests.** Through `HeadlessBackend` over `builtins::registry()`:
   every op; the Phase 5 flowchart built with `Invoke` alone and checked
   with the inspect ops (the in-process twin of P9-11's end-to-end
   test); a command needing a path without it (`NeedsInput` with
   `data`); `app.quit` attached (`Denied`) and headless (runs, reports
   `quit`); `tools.agent_control` refused; a dirty `file.close`
   (`confirm_close`, still open); every policy refusal with temporary
   directories; undo of a remote edit with `edit.undo`.
