## Goal

Implement the two-page wizard of ADR 0066 in `crates/ui/src/wizard.rs`:

1. **Page 1, Welcome.** Left half `about_screen.svg` scaled to fit
   with its 16:10 ratio; right half with the title **Larrygram v1.0
   alpha**, the short description (ADR 0066, verbatim) and the
   **Why Larrygram?** button that calls `about::show`. Bottom row:
   **Cancel** and **Next**.
2. **Page 2, Choose your layout.** Two large buttons side by side,
   each showing its picture with the name under it: **Panel Modern**
   (`panel-layout.svg`, selected by default) and **Panel Classic**
   (`classic-layout.svg`). Bottom row: **Back** and **Start**.
3. **Flow.** Next and Back move inside `wizard::State`. Start returns
   `Outcome::Start { default_layout }` and Cancel returns
   `Outcome::Cancel`; the caller (the shell, P7-09) writes
   `WelcomeSettings { welcome_seen: true, .. }`, applies the layout at
   once and closes the wizard. Cancel keeps Panel Modern.
4. **Images.** Load the three SVGs through the ADR 0067 loader: R5
   put it in `main`, so embed the bytes (`egui::include_image!` or
   `ctx.include_bytes`) and draw them with `egui::Image`. Tests call
   `larrygram_ui::install_image_loaders` on the harness context first.
   Nothing is rasterised at build time.
5. **Text.** The About text and the wizard copy come from ADR 0066
   verbatim; no other long-form text is copied.
