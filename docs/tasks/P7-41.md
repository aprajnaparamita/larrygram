## Why

The P7-37 review (2026-11-03) found that formatting by mouse ends the
typing. A click on Bold, a size or an alignment counts as a press
outside the editor (the P7-29 rule), so it commits:

- on an empty new box, Bold closes the editor, the group is cancelled
  and the box is gone; the next keystrokes go nowhere;
- after typing, Bold closes the editor and the stack reads
  `["Insert Text Box", "Bold"]`; every later format click adds a step.

Cmd+B works (the editor stays open, one step). The P7-37 test checked
only the first undo label, so it passed with four steps.

## Goal

1. **Format clicks don't commit** (review 1). A click on a control
   whose command is a text-format command (the `TEXT_CONTROLS` set the
   P7-37 allowlist rule names, or what `can_format_text` gates, one
   source of truth either way) does not end the edit, for a new box and
   for an existing shape's edit alike. The command applies to the
   shape being edited, the editor keeps keyboard focus and the caret,
   and for a new box the edit lands in the open group. Popups and
   dropdowns for those commands (the font size list, the colour
   picker) behave the same: choosing a value keeps editing.
2. **Tests that would have caught it** (review 2). In both layouts, by
   real input:
   - Text tool click, Bold before typing, type, Escape: the text is
     bold, the editor stayed open after Bold, and the stack is exactly
     `["Insert Text Box"]`;
   - type, Bold, type more, a font size from the list, Escape: still
     editing after each click, all text kept, one step;
   - the same on an existing shape's edit: one step per format click
     (as Visio), the editor still open;
   - Cmd+B while typing folds into the group (the path the review
     probed by hand).
   Assert the full undo label list and the editing state after every
   click.
3. **Save while typing** (review 5). Check whether Cmd+S, Save As,
   export and print dispatch while the editor has focus. Any `file.*`
   command commits the open box first, so a save never writes an
   empty box. Test it.
4. **No hand-kept trigger list** (review 6). Replace
   `TEXT_BOX_TRIGGERS` with a rule: every command commits the editor
   first except the text-format set of item 1 and the editor's own
   commands. A test pins that a new `file.*` or layout command
   commits.
5. **Undo while a box is open** (review 7). `can_undo` reports true
   while a non-empty group is open, and Undo commits the box and then
   undoes it whole.
6. **A failed cancel** (review 8). If a revert inside `cancel_group`
   fails, push the edits that were not reverted as one step labelled
   as the group, report the error, and leave the stack consistent.
   Unit test with a failing edit.
7. **The new shape's id** (review 9). `insert.drawing.text_box`
   returns the new shape's id in its outcome; `open_text_box` uses it
   instead of the selection anchor.
8. **ADR 0040** (review 10). The amendment shows the real
   signatures: `UndoStack::begin_group(label, unsaved)` and
   `AppCtx::begin_group(session, label)`.
