## Goal

1. **Current context.** `contexts::current(&AppCtx) -> ContextId`,
   following the rules in ADR 0064. Shape kinds come from the model:
   - a picture is a foreign-data shape;
   - a container has the container `User.msvStructureType` cell value;
   - a group has sub-shapes;
   - a connector has 1-D glue (the Phase 5 connector).
2. **Hit target to context menu.** `contexts::menu_for(hit) ->
   Option<&ContextMenuV2>` for both layouts.
3. **Test documents.** One document per context, built in code with
   the model API (no corpus files needed).
4. **Cross-check test.** For every implemented command, evaluate the
   enabled predicate in each non-pending context and compare it with
   `enabled_in`.
   - A mismatch fails the test unless the command is on an allow-list
     with a reason.
   - Fix real predicate bugs in `crates/commands`.
5. **Toggle defaults.** Check the `on_by_default` toggles against the
   `Settings` and `ViewState` defaults, and list any differences.

- `feat(ui): compute selection contexts and map context menus` —
  `crates/ui/src/contexts.rs` replaces the P7-01 stub. `current` and
  `current_with(&AppCtx, &ContextState)` follow ADR 0064: a picture is

  maps onto the frozen `ui_spec::v2::ContextId` (a selected page counts
  as `empty_page`). `menu_for(&LayoutV2, HitTarget) ->
  Option<&ContextMenuV2>` maps a hit target to the layout's context
  menu for both committed layouts, `None` for a target the layout does
  not define.
