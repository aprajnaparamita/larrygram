## Goal

1. **Duplicated geometry points**: a geometry row list carries the
   rows and points the drawing has, without the duplicates (the
   `no-bgcolor` box has twice the reference's vertices).
2. **`NoLine`, `NoFill`, `NoShow`** reach the renderer per geometry
   section (P8-15 open issue 1). Prove it with a `.vsdx` test first.
3. **Dimension shapes** in `Visio6PlanWithDimensions` draw their
   labels.
4. **Open sub-paths** fill as Visio fills them (the wedges); settle it
   against the twins' PDFs.
5. **Text boxes**: the text transform (`TxtPinX` and friends) lands on
   the right shape and the right box; text sits where the reference
   puts it.
6. **Field display text**: a field prints its computed value in the
   cell's format (`10'-0"`, dates, currency, angles), not its
   placeholder. If a format needs the ShapeSheet engine, use what
   `crates/shapesheet` already offers through the model; say so in the
   Result if something is missing.
7. **The twin comparison runs on the twins** once they are present:
   move the format-agnostic comparison to
   `crates/render/tests/twins/compare.rs` (MIT, no MPL header), include
   it from both test suites, and report the result per file (cells
   that agree, cells that differ, and why).
8. **Wide-corpus check**: before hand-off, run the import sweep
   (`LARRYGRAM_WIDE_CORPUS=/Volumes/Dara/larrygram/reference/wide-corpus
   cargo test -p larrygram-vsd-binary --test wide_corpus -- --ignored
   wide_corpus_import_sweep`) and report panics (must stay 0), files
   opened (P8-16: 2 784) and group shapes (P8-16: 0). Name no file in
   the repo.
