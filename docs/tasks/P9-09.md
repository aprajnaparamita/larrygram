## Goal

1. **`remote.rs`.** `RemoteBackend::connect` (read the discovery file,
   connect, `hello` with the token and the client name, keep the
   `ServerInfo`) and `call` (one request per op through
   `protocol::encode_op` and `decode_result`; server errors as
   `ControlError::Remote`; a dropped connection is `Io`).
2. **`larrygram-cli serve`.** The control protocol over stdio:
   `ControlServer` without a token over a `HeadlessBackend` (the
   builtin host, an executor with `attached: false` and the policy
   roots: the working directory plus each `--allow-dir`). Exit 0 at end
   of input; 3 on an I/O failure of stdout.
3. **`larrygram-cli mcp`.** The same with `McpServer`.
   **`larrygram-cli mcp --attach`**: `McpServer` over a
   `RemoteBackend` to the running app (`--runtime-dir` overrides the
   discovery directory for tests). A missing app is one stderr line
   naming what to do, exit 2.
4. **Hygiene.** Nothing but protocol frames on stdout in `serve` and
   `mcp`; warnings and logs on stderr, one line each; `--help` lists
   the new subcommands and flags.
5. **Tests.** Parser tests for the new flags; `serve` and `mcp` driven
   in-process over byte buffers (`discover`, a command, an inspect, a
   render); `mcp --attach` against a listener started in the test
   (P9-06's `Listener` over a `HeadlessBackend`) in a temporary
   runtime directory.
