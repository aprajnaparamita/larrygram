## Goal

1. **`auth.rs`.** `Token::generate` (getrandom; failure is `Internal`),
   `to_hex`, `from_hex`, `verify` in constant time (compare every byte
   whatever the first difference; a wrong length is false).
2. **`transport.rs`.** `runtime_dir` (per platform, created `0700` on
   Unix, `LARRYGRAM_RUNTIME_DIR` override), `write_discovery` (`0600`,
   written to a temporary name then renamed), `read_discovery`
   (`NotFound` with a hint when missing), `Listener::bind` (Unix socket
   `control.sock` in the directory, `0600`; a stale socket of a dead
   process removed; a live one `Busy`. Windows: `127.0.0.1:0`; the
   Windows branch is compiled only on Windows, so keep it small and
   say in the Result that it is untested here), `Listener::spawn` (the
   accept thread, one thread per connection up to
   `max_connections`, the hello timeout as a read timeout until the
   front end is ready, a stop flag), `ListenerHandle::{connections,
   stop}` and `Drop`, `Connection::connect` and the byte-stream
   access the remote backend needs (add `Read`/`Write` impls or an
   accessor; that is within your file).
3. **`inbox.rs`.** `InboxSender::call` (send, wake, wait with the
   timeout; a closed inbox or a timeout is `Busy`), `Inbox::drain`
   (non-blocking, at most `max_ops`, each answer sent back; a caller
   that gave up is ignored).
4. **Tests.** Token round trips and a wrong token; the discovery file's
   mode on Unix; bind, connect, a trivial echo front end, the sixth
   connection refused at a cap of five, stop removes the files; the
   inbox across threads (answers equal a direct `Executor::execute` on
   the same host, whatever it returns), the timeout with a host that
   never drains, a dropped inbox. Use a temporary runtime directory
   per test; never the user's real one.
