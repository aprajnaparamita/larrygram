## Goal

1. **End-to-end tests.** Every corpus `.vsd` opens and renders; the
   round-trip test (open `.vsd`, save `.vsdx`, reopen) keeps the model
   equal (the model `diff`); the two `fdo86729` files give the same
   text.
2. **Malformed inputs.** Hand-authored malformed fixtures (committed,
   MIT, listed in `corpus/PROVENANCE.md`): truncated container, bad
   FAT, lying record lengths, pointer cycles, absurd counts. Each must
   error or warn, never panic; every case gets a test.
3. **The fuzz target.** `crates/vsd-binary/fuzz/` with one target
   driving `import` over mutated bytes; seeds from the corpus files.
   `cargo +nightly fuzz build` green in the gate.
4. **Golden images.** Render the imported corpus drawings to PNG
   goldens (the existing golden harness), so a mapping change that
   moves geometry or text shows up.
5. **The report.** `docs/reviews/phase-8-tests.md`: what is covered,
   what is not, and the parity numbers as P8-08 reported them.
