## Goal

1. **One resolution** (rule 3). `larrygram_geom::glue` resolves both
   ends together, and draw, glue, unglue and every re-route call it:
   - point glue goes to the row's point;
   - a dynamic end facing a fixed end takes the candidate nearest the
     fixed point;
   - two dynamic ends use `resolve_pair` (nearest pair, ties to the
     lower index on the begin target, then on the end target);
   - a target with no connection points offers its four local side
     midpoints through its transform;
   - free ends stay on their endpoint cells.

   `nearest_on_rect` and `rect_center` go. The cached endpoint values
   and the glue formulas (P7-31) take the resolved points.
2. **Draw time uses the drag.** `connector.draw` resolves a glued end
   with the same function, and a free end at the point where the user
   released. No master default endpoints are involved.
3. **Exit directions** (rule 4). Each resolved glued end has an exit
   direction: the row's `DirX`/`DirY` when non-zero, otherwise the
   outward normal of its side. A right-angle route leaves along it
   with a 0.25 in stub and joins the stubs with axis-aligned segments
   (the Z, L and U cases). It never runs back along the shape's own
   edge.
4. **Re-route only what the edit touched** (rule 5). The hook takes
   the shapes the edit changed. It re-routes only connectors with an
   end glued to one of them, and connectors whose own ends or style
   changed. The re-route happens inside the edit, so one undo restores
   shapes and routes together. A route Visio drew, on a connector
   whose targets did not move, keeps its geometry rows byte for byte
   through an unrelated edit and a save.
5. **The drawing glue rule** (rule 6, first bullet). `locate` gives:
   - point glue within the snap distance of a connection point;
   - otherwise dynamic glue to the topmost **non-connector** shape
     whose outline contains the pointer;
   - otherwise free.

   Connectors are never glue targets. Alt suppresses glue, as today.

## Interfaces

```rust
// crates/geom/src/glue.rs (L0, pure geometry, page inches)

/// One point a target offers a glued end, with its exit direction
/// (a unit vector as a `Point`, or `None` for no preference).
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Candidate {
    /// The page-space point.
    pub point: Point,
    /// The direction a route leaves the point in, page space.
    pub exit: Option<Point>,
}

/// The facts one glue target offers.
#[derive(Debug, Clone, PartialEq)]
pub struct GlueTarget {
    /// The target's connection points as `(row ix, local point, local
    /// direction)`, the direction `None` when `DirX`/`DirY` are zero.
    pub points: Vec<(u32, Point, Option<Point>)>,
    /// The target's local box (0,0 to Width,Height).
    pub local_box: Rect,
    /// Local to page.
    pub transform: Transform,
}

/// What one end is glued to.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum GlueEnd {
    /// The connection row with this zero-based index.
    Point(u32),
    /// The shape (dynamic glue).
    Shape,
}

impl GlueTarget {
    /// The candidates for dynamic glue: the connection points, or the
    /// four side midpoints when there are none (ADR 0084 rule 3).
    pub fn candidates(&self) -> Vec<Candidate>;
}

/// One end as the resolver sees it.
#[derive(Debug, Clone, PartialEq)]
pub enum EndSpec<'a> {
    /// Glued to `target`.
    Glued(&'a GlueTarget, GlueEnd),
    /// Free at this page point.
    Free(Point),
}

/// Resolves both ends of one connector (ADR 0084 rule 3). Never panics;
/// a non-finite input falls back to the target's first candidate, and a
/// missing point row falls back to dynamic glue and reports it in the
/// returned flag.
pub fn resolve_ends(begin: &EndSpec<'_>, end: &EndSpec<'_>) -> (Candidate, Candidate, bool);

/// The nearest candidate pair, one from each slice; ties to the lower
/// index in `a`, then in `b`. `None` when either slice is empty.
pub fn resolve_pair(a: &[Candidate], b: &[Candidate]) -> Option<(usize, usize)>;
```

  - a drag that ends over a connector does not glue to the connector.
