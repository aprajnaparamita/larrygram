## Goal

A user can drag a connector's begin or end handle to a new place:

- Drop on a shape's connection point: point glue (a `Connect` record
  to that row) and the end sits on the point.
- Drop on a shape's outline: dynamic glue and the end sits on the
  rule from P7-31.
- Drop on empty space: the end is unglued and stays where dropped.
- While hovering during the drag, the glue target under the pointer
  highlights (the shape's outline or the specific connection point),
  so the user sees what the end will glue to before release.
- A selected connector shows its glue state at the ends (glued ends
  one marker, free ends another), matching the spec's green-vs-white
  convention in our own theme colours.
- Every drag is one undoable command; Alt disables glue while
  dragging (consistent with the connector tool).

## Interfaces

```rust
// crates/commands/src/builtins/connector_ends.rs

/// `connector.move_end`: one undoable move of one connector end.
///
/// Arguments: `connector` (Visio id), `end` ("begin" | "end"),
/// `x`, `y` (page inches), optional `target` (Visio id) and optional
/// `point` (connection row `IX`). With `target`/`point` the end is
/// glued on drop (point glue when `point` is given, dynamic glue
/// otherwise); without them the end is free and lands at `x`,`y`.
/// Runs P7-31's resolution and rewrites the path in the same edit.
pub(crate) fn run_move_end(ctx: &mut AppCtx, inv: &Invocation) -> Result<Outcome, CommandError>;
```

```rust
// crates/render/src/overlay.rs (new mark)

/// One hover highlight: the outline of the shape (or the point) that
/// a dragged connector end will glue to.
pub enum OverlayMark {
    // ... existing variants ...
    GlueTarget { outline: Vec<Point>, point: Option<Point> },
}
```

The tool's connector state machine gains an `EndDrag` mode: press on a
selected connector's end handle (or on the end of a selected
connector), move with hover resolution (`GlueTarget` overlay), release
emitting one `connector.move_end` intent.
