## Goal

1. **Normalise drawing units in the comparison.** A `.vsdx` twin keeps
   a scaled drawing's lengths in drawing units with the scale cells
   beside them; the model stores physical inches (ADR 0070). Convert
   the twin's lengths by `PageScale`/`DrawingScale` before comparing,
   so a scaled drawing's lengths stop showing as mismatches. Re-run the
   17-file twin test (`LARRYGRAM_VSD_TWINS`) and report the change
   per file.
2. **The wide twin sweep** (`crates/render/tests/wide_twins.rs`,
   ignored, skips cleanly unless `LARRYGRAM_WIDE_TWINS` and
   `LARRYGRAM_WIDE_CORPUS` are set): for each of the 77 converted
   files, compare `import(<original>)` with the `.vsdx` reader's
   document for its twin, with the comparison of goal 1. Write a local
   CSV (per file: pages, shapes joined, cells compared, cells that
   agree, mismatches by cell family) and print totals.
3. **Pictures** (local only): render every page of all 206 files with
   our renderer, rasterise Visio's PDFs at the same width (the system
   `pdftoppm`; skip with a note if it is missing), and write a local
   side-by-side page,
   `/Volumes/Dara/larrygram/reference/wide-twins/compare.html`, with a
   per-page difference score (the ADR 0027 metric). Sort it worst
   first.
4. **Skip empty drawings in the selection.** In `cargo xtask scout
   select`, a drawing is eligible only if at least one page holds a
   shape that page references (orphan records do not count; for `.vsd`
   the count comes from the import's page trees, not from its shape
   list). Stencils and templates stay eligible by their masters.
   Refill freed slots from the same bucket; unit-test the rule with
   hand-built index rows; regenerate `export-set.csv` and the
   gate-corpus proposals locally and report how many files changed.
5. **The report**: a new section of `docs/reviews/wide-corpus.md`,
   aggregates only: agreement by cell family over the 77 files, the
   ten most common mismatch causes, the score distribution of goal 3.
   Name no file. The Result lists each fault class the sweep finds,
   with the layer it belongs to.

### What was built

1. **Drawing units in the comparison** (goal 1,
   `crates/render/tests/twins/compare.rs`). The comparison multiplies
   the **twin's** lengths by the page's `|PageScale / DrawingScale|`
   before it compares (the import's scale pass in reverse: a zero
   `DrawingScale` divides as 1, a missing or unusable pair scales by
   1). Only what is a length scales: the stated cells and the
   documented formula defaults (`LocPinX = Width*0.5` derive from the
   twin's own drawing units), while a documented constant default (the
   margins' "0.1 inch", ADR 0021) is a physical quantity and does not.
   Geometry row cells scale by what the cell *is* per row kind
   (ADR 0022): `EllipticalArcTo`'s C/D (angle, ratio), `NurbsTo`'s
   knots and weights, the spline knots and the `Rel*` fractions never
   scale. The rule is the semantic one (a length, not "what the import
   happens to scale"), so a length the import forgets to scale shows
   up as a fault instead of hiding.
2. **The wide twin sweep** (goal 2, `crates/render/tests/wide_twins.rs`,
   `#[ignore]`, skips cleanly without the two environment values). For
   each of the 77 converted files it imports the original (either
   reader, by extension) and compares it with the `.vsdx` reader's
   document for its twin, under `catch_unwind`: a panic is recorded,
   never a crash of the sweep. It writes the local
   `reference/wide-twins/twin-sweep.csv` (pages, shapes joined, cells
   compared, cells that agree, mismatches by cell family) and
   `twin-sweep-causes.csv` (cause, family, mismatches, files) and
   prints the totals.
3. **The picture page** (goal 3, the same file). Every page of all 206
   export-set files renders with our renderer at 600 px wide
   (background pages composited, `corpus_vsd.rs`'s rule); Visio's PDF
   rasterises at the same width with the system `pdftoppm` (present
   here: poppler 25.09.1; the test skips with a note when it is
   missing). The pair scores with the ADR 0027 metric as a score (the
   fraction of pixels whose channels differ by more than 2 of 255,
   over the common area, composited over white). Outputs, local only:
   `compare.html` (worst first, our raster beside Visio's),
   `picture-scores.csv`, `our-png/`, `pdf-png/`.
4. **Empty drawings out of the selection** (goal 4,
   `xtask/src/scout.rs`): a candidate is eligible only when
   `page_shapes >= 1` (the shapes the page trees reference), or it is
   a stencil or template by extension with masters. The two wide
   sweeps record the new `page_shapes` column (each counts the page
   trees with a bounded iterative walk and pins the orphan rule with a
   hand-built document); a sweep that does not write the column leaves
   it zero and its files are never eligible. Unit tests with hand-built
   index rows cover the empty drawing, the same-bucket refill, the
   stencil/template carve-out and the page-trees-not-shape-list rule.
5. **The report** (goal 5): `docs/reviews/wide-corpus.md` gains "The
   twin sweep (task P8-21)": method, agreement by cell family, the ten
   most common mismatch causes, the score distribution. Aggregates
   only, no file named.
