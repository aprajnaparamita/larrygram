## Goal

1. **Normalise drawing units in the comparison.** A `.vsdx` twin keeps
   a scaled drawing's lengths in drawing units with the scale cells
   beside them; the model stores physical inches (ADR 0070). Convert
   the twin's lengths by `PageScale`/`DrawingScale` before comparing,
   so a scaled drawing's lengths stop showing as mismatches. Re-run
   the 17-file twin test (`LARRYGRAM_VSD_TWINS`) and report the change
   per file.
2. **The wide twin sweep** (`crates/render/tests/wide_twins.rs`,
   ignored, skips cleanly unless `LARRYGRAM_WIDE_TWINS` and
   `LARRYGRAM_WIDE_CORPUS` are set): for each of the 77 converted
   files, compare `import(<original>)` with the `.vsdx` reader's
   document for its twin, with the comparison of goal 1. Write a local
   CSV (per file: pages, shapes joined, cells compared, cells that
   agree, mismatches by cell family) and print totals.
3. **Pictures** (local only): render every page of all 206 files with
   our renderer, rasterise Visio's PDFs at the same width (the system
   `pdftoppm`; skip with a note if it is missing), and write a local
   side-by-side page,
   `/Volumes/Dara/larrygram/reference/wide-twins/compare.html`, with
   a per-page difference score (the ADR 0027 metric). Sort it worst
   first.
4. **Skip empty drawings in the selection.** In `cargo xtask scout
   select`, a drawing is eligible only if at least one page holds a
   shape that page references (orphan records do not count; for
   `.vsd` the count comes from the import's page trees, not from its
   shape list). Stencils and templates stay eligible by their masters.
   Refill freed slots from the same bucket; unit-test the rule with
   hand-built index rows; regenerate `export-set.csv` and the
   gate-corpus proposals locally and report how many files changed.
5. **The report**: a new section of `docs/reviews/wide-corpus.md`,
   aggregates only: agreement by cell family over the 77 files, the
   ten most common mismatch causes, the score distribution of goal 3.
   Name no file. The Result lists each fault class the sweep finds,
   with the layer it belongs to.
