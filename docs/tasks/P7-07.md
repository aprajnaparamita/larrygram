## Goal

Render every panel-modern v2 layout as described in `docs/ui/panel-modern.md`:

1. **Tab strip** with the File button and upper-case captions.
   Contextual tab sets come from the current context (P7-08 supplies a
   `ContextId`; until it merges, take it as a parameter).
2. **Groups.**
   - `stack` and `rows` layouts from `column` and `row`.
   - `large`, `medium` and `small` sizes, checks and combos.
   - Launchers and captions.
3. **Controls.**
   - Split buttons: the icon part and the arrow part.
   - Dropdowns: menus with a gutter, options, lists and submenus.
   - Galleries: a grid of `list` entries, with a "(none)" placeholder.
4. **Command-bar chrome.**
   - Collapse and expand: double-click, Ctrl+F1, the overlay when
     collapsed.
   - The QAT, with dynamic labels for Undo and Redo.
5. **File view**: the nav column, pages (Info, New, Open, Save As,
   Print, Export) as described, the commands, and the back button.
6. **Fluent-data layouts.** The 2016 and 365 layouts render through
   the adapter. Keep the ADR 0031 display dedup rule for v1 data.

### What was built

- **`crates/ui/src/panel_modern.rs`** — the `PanelModern` state (the
  active core and contextual tab, collapse state, overlay, File view,
  display-only toggles). It draws the tab strip (File button, upper-
  case captions, contextual tab sets with their caption block), the
  command bar (groups with captions, separators and launchers, the ^
  collapse button), the collapsed overlay (an `Area` under the tab
  strip that closes after a command runs or on a click elsewhere),
  Ctrl+F1 and double-click collapse, and mouse-wheel tab switching.
  Contextual tabs come from the `SelectionContext` parameter (ADR
  0064); a contextual tab whose context ends returns the bar to the
  last core tab.
- **`crates/ui/src/panel_modern/metrics.rs`** — the widget sizes as a
  `Metrics` struct. `Metrics::from_theme` reads the
  `ui-spec/themes/panel-modern.yaml` tokens with safe fallbacks (a
  missing, non-finite or non-positive token keeps its default); the
  defaults are the committed theme values.
- **`crates/ui/src/panel_modern/place.rs`** — the placement math:
  `stack` and `rows` slots from `column`/`row`/`size`, large controls
  spanning the group height, `rows.gap` cluster gaps, clamped
  out-of-range slots, and flow placement for adapted v1 groups (first
  control with a menu is large, the rest medium). Also the ADR 0031
  display dedup rule (first occurrence of an `(id, label)` repeat
  wins) and the hidden-control filter.
- **`crates/ui/src/panel_modern/common.rs`** — the ADR 0031/0028
  action rules (`Resolve` seam, registry resolution, out-of-scope
  tooltips), dynamic labels ("Undo <action>", "Repeat <action>",
  "Can't Undo", "Can't Redo") and the painted arrow atoms (egui's
  fonts have no triangle or arrow glyph).
- **`crates/ui/src/panel_modern/controls.rs`** — the control kinds at
  their sizes: large/medium/small buttons, checks, combos, splits
  (icon part runs `command`, arrow part opens the menu; large splits
  divide horizontally), dropdowns (menu with the 24 px icon gutter,
  options rows, `list` rows, submenus) and galleries (a grid of `list`
  entries with a "(none)" placeholder).
- **`crates/ui/src/panel_modern/tests.rs`** — the ADR 0065 placement
  test over every group of the committed `panel-modern.yaml`, the
  adapted-flow/dedup test, and `egui_kittest` tests: each tab, the
  Paste split (icon part dispatches `edit.paste`, arrow part opens the
  menu and its entries dispatch), a launcher dispatch
  (`format.all.text.props`), a gallery opening its "(none)"
  placeholder, collapse and expand (button, double-click, Ctrl+F1,
  overlay), the File view (open, Esc, back button, Save dispatching
  `file.save` and closing, page switching) and the contextual tabs of
  the three contexts.
- **`crates/ui/src/file_view.rs`** — the File view: the 123 px nav
  column with the back button, page/command nav entries, and the
  pages (Info with the document properties, path and protection
  status; New with the template tiles and Blank Drawing; Open with the
  numbered recent files and Browse; Save As with Browse; Print with
  its settings; Export with PNG, SVG and PDF).
- The Quick Access Toolbar (`PanelModern::show_qat`): Save, the Undo
  split with the history list, Redo and the customise dropdown, which
  shows the current items as checked and disabled.

### Deviations from the task file

- The P7-01 stub `show(ui, layout, context)` cannot hold widget state
  or resolve commands. The closest correct interface is the
  `PanelModern` struct (mirroring `TabBar`): `show(ui, layout,
  context, app, lists, registry)` and `show_qat(ui, layout, app,
  registry)`, with the `show_with`/`show_qat_with` resolver seam the
  tests drive. The stub test is replaced by the real widget tests.
- Run-time `list` data reaches the widgets through the new `ListData`
  table (empty lists draw "(none)"). P7-09 fills it.
- Sizes come from `Metrics` (`from_theme` for P7-09); colours are
  egui defaults, as the task says until P7-05 merges.
- Combos render as a framed box with an arrow and their `options` as
  the popup; they are not editable text boxes yet (Panel Classic
  parity with P7-06 refines this).
- Adapted Fluent-data layouts (the P7-03 adapter) are covered by the
  flow-placement and dedup rules with hand-built values; rendering a
  loaded 2016/365 layout through the adapter is wired in P7-09.
- The tooltips show the label and the shortcut in brackets. The
  one-sentence description the spec wants has no source yet (see Open
  issues).
- Menu access letters are not underlined. Submenus open on hover or
  click with egui's `SubMenuButton`, with the children beside the
  row; the first cut used `MenuButton`, which closes the children
  together with the parent menu.

### Open issues

- **Command descriptions for tooltips.** `CommandMeta` (and
  `commands.yaml`) carry no description field, so the "one sentence of
  our own text" cannot be drawn yet. Needs a `description` on the
  command metadata (P7-02/P7-09 domain).
- **Menu access keys.** Alt+letter handling and the underlined access
  letters need the shared menu machinery (the same need as P7-06).
- **Theme colours.** The contextual tab-set colours and the File view
  colours use egui defaults; P7-05's `theme::apply` and a
  `Metrics::from_theme` call in P7-09 finish the look. The tab
  captions keep their chrome outline painting provisional.
- **File view dialogs.** Browse (native dialog/upload/download) and
  the print/exports dispatch `file.open`, `file.save_as`,
  `file.print` and `file.export`; the shell (P7-09) must give those
  commands their dialog behaviour.
