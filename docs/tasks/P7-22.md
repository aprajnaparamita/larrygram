## Goal

1. **The Delete key does nothing** on a selected shape or text box; it
   must delete the selection (`edit.clear`, P7-20). Find where the key
   is lost (canvas focus, a text-edit consumer, the shortcut filter)
   and fix it there.
2. **Right-clicking a selected group** offers no Group or Ungroup. The
   shape context menu offers Group with two or more shapes selected and
   Ungroup on a group, plus the arrange basics P7-21 built (bring to
   front, send to back, rotate, flip).
3. **Cut on a shape inside a group** cuts only that shape. A first
   click on any member selects the whole group, as Visio does; a
   second click on the selected group subselects the member. Cut,
   Copy, Delete and the context menu then act on what is selected,
   which is the whole group after one click.
4. **Insert > Text Box** (and its Horizontal and Vertical items) is
   disabled on a new document. `insert.text.box` and
   `insert.vert.text.box` must work: they switch to the text tool (or
   place a text box at the page centre, your choice; say which).
5. **Insert > Picture** is disabled. Implement inserting a PNG or JPEG
   from a file as an image shape (the shell's file dialog asks for the
   path; the command takes `path` as an argument). The image must
   render, save to `.vsdx` and reopen. If the model or writer cannot
   carry an image yet, say what is missing and stop at that boundary
   with a clear disabled reason.
6. **No right-click menu offers Delete** (or Clear): the shape
   context menu gets Delete, enabled with a selection (user's second
   pass, 2026-10-31). The second pass also confirmed item 1 on every
   kind of shape, a text object included.
7. **Flip does not draw** (P7-21's open issue): `render` honours
   `FlipX` and `FlipY`, including inside groups and on text.
