1. **Nothing is dropped silently any more** (P8-11 F1, blocker). The
   drop policy moved beside the id table in `crates/vsd-binary/src/chunks.rs`
   (`Record::dropped_what`, `Record::is_mapped`): a record kind the
   importer drops warns `Dropped` with what it carries (ADR 0070's

   connection-point and control rows and the sheet rows no module
   maps: scratch, protection, misc, style-sheet properties, group,
   layout, image), a kind no module consumes warns `SkippedRecord`

   `KNOWN` list that hid the bug is gone, the comment above it is
   rewritten, and the silent `PROP_LIST` arm of `pages.rs` is closed.
   Regression tests pin every family's warning and the silence of the
   mapped ones (`every_dropped_kind_names_what_it_carries`,
   `the_deferred_row_families_warn_inside_a_shape`,
   `user_cell_rows_at_page_scope_warn`).
2. **Layers and layer membership map for real** (the ADR 0070 row the
   audits named, amended 2026-10-26). A page sheet gains its `Layer`
   rows (`Name`, `NameUniv`, `Color`, `Visible`, `Print`, with the row
   `IX`) and a shape its `LayerMember` cell. The row spelling matches
   a Visio twin's `Layers` rows one for one (checked against
   `vsd-twins/vsdx/Visio11TextFieldsWithUnits.vsdx` and
