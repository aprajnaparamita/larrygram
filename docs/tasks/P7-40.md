## Why

Found while preparing P7-37 (2026-11-03). An instance whose text
lives on its master shows no text in Larrygram: `build_text`
(`crates/render/src/build.rs` around line 1774) reads only the
shape's own `text`, the readers copy no master text into instances,
and the model has no inherited-text lookup. `shape_has_text` has the
same gap, so the text controls are disabled on such a shape. Visio
draws the master's text when the instance has none of its own.

## Goal

1. **One lookup.** `Document::effective_text(shape) -> Option<&TextContent>`:
   the shape's own text if it has a `Text` element (even an empty
   one), otherwise the text of the matching master shape, following
   the master chain the way `master_chain_shapes` does, with its depth
   bound. Never panics; a broken chain gives `None`.
2. **The renderer draws it.** `build_text` uses `effective_text`.
   Formatting already comes through the inherited Character and
   Paragraph cells; check that a master's run formatting applies.
3. **The controls follow it.** `shape_has_text` uses `effective_text`.
4. **Editing it.** Opening the editor on such an instance starts with
   the master's text. Committing a change writes the instance's own
   text, so the master is never edited. Committing unchanged text
   writes nothing and pushes no undo entry.
5. **Count it.** Count the instances in the local corpus (`corpus/vsdx`
   and `corpus/vsd`) that have no text of their own and whose master
   shape has text, and put the count per file in the Result.

## Tests

- **Model**: own text wins; empty own text wins; master text when
  there is none; a two-rung chain; a cycle and a missing master give
  `None`.
- **Render**: an instance of a master with text draws it (scene and
  pixels). Every corpus golden that changes is listed in the Result
  with its file and why, and looked at as an image diff (ADR 0027).
- **Real input** (egui_kittest, full shell, Panel Modern and Panel
  Classic): open a document whose instance inherits text, check the
  text is drawn, select it and check the text controls are enabled,
  double-click it, type, commit, and check the instance now has its
  own text and the master's is unchanged. One undo puts it back.
