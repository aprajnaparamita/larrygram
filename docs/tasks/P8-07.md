## Goal

1. **Pages.** Page, page-sheet and page-property records to `Page`
   values: names, `visio_id`, page size and background-page references
   (`Page::background` resolved to a `PageId` or a warning), the page
   sheet cells, and connect records to `Page::connects`.
2. **Masters.** Stencil, stencil-page and master-shape records to
   `Master` values with their top-level shapes; name-list records to
   the `name` and `name_u` of pages, masters and shapes; unresolved
   names are warnings (ADR 0071).
3. **Kind and properties.** `Document::kind` from the records (stencil
   pages mean `Stencil`, the template marker `Template`), and document
   properties from the property records and the summary streams
   (ADR 0070).
4. **The pipeline.** Implement `pipeline::import`: read the streams,
   read the version, read the chunks, run the four `collect` functions
   in the order ADR 0070 implies (styles first, then pages and
   masters, then shapes, then text), and return `Import` with every
   warning. The `Error::NotImplemented` variant loses its last caller
   here; leave the variant itself for the fix task.
5. **The smoke test.** `crates/vsd-binary/tests/import_smoke.rs`: each
   corpus `.vsd` opens without a panic and yields a document with the
   expected pages, shapes and text (assert what the corpus files
   contain; a wrong expectation is corrected only with evidence).

## Master notes

P8-02 to P8-06 are merged. Their Result sections list what the
pipeline must wire; the points you must act on:

- **Seams that changed from the P8-01 stubs.**
  - `chunks::read_chunks` returns `(Vec<Chunk>, Vec<ImportWarning>)`
    and takes a block store, `blocks: &mut Vec<Vec<u8>>`, that must
    outlive the chunks (P8-03, deviation 1).
  - `shape::collect_with(chunks, version, limits, document, warnings)`
    sits beside the frozen `collect` (P8-04); `text` has the same
    pattern and needs the stream version and the summary code page
    (P8-05).
  - `style` decodes version 6 style names as UTF-16 only; give it the
    same version seam (P8-06, open issue).
- **`#![allow(dead_code)]`** in `container.rs` and `style.rs` exists
  only until the pipeline calls them: remove both, and re-export the
  reader entry points from `lib.rs` (P8-02).
- **Joins.** `text` assumes shapes are in the arena in stream order:
  check that against `shape`'s output (P8-05). The shape record's
  parent field is unused because levels define nesting; if the
  flattened levels do not nest sub-shape streams, that field is the
  fallback (P8-04, open issue b).
- **Unmapped fields, decide and record:** the shape record's
  master-shape field has no model slot (P8-04); the `Font` cell of
  style character rows is set by neither `style` nor `text` (P8-06).
- **Warnings.** Font records: `style` warns `Dropped` once per record
  and `text` warns `BadValue` only for an undecodable name; they are
  different facts, keep both (P8-06, open issue 3).
- For P8-10, not you: the `FlipX`/`FlipY` kind (`Bool` here, `Number`
  from the `.vsdx` reader) and the record kinds the census should name.
