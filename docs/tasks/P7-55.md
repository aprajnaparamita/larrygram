## Goal

1. Find the uncovered lines and regions in the two crates. A
   per-crate run is allowed: `cargo llvm-cov -p larrygram-commands
   --all-features --html` (and the same for `larrygram-ui`), and the
   same command with `--text`. Start with the files the Phase 7
   tasks touched (`git log --since=2026-11-01 --name-only -- crates/commands/src crates/ui/src`).
   The ratchet is checked on the workspace run, which also counts other
   crates' tests, so treat the per-crate number as a lower bound.
2. Add tests that exercise real behaviour: error arms with the
   message they report, the no-document and no-selection paths,
   Cancel and invalid-input paths of the dialogs, the undo and redo
   of each new command. UI tests use real input through egui_kittest
   (both layouts where the control exists). No test that only calls a
   function to touch its lines without an assertion about the result.
3. Reach commands >= 98.4% and ui >= 97.0% in the hand-off gate's
   coverage step, with some margin (aim for 98.5% and 97.1%).
