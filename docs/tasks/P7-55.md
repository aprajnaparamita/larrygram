   coverage step, with some margin (aim for 98.5% and 97.1%).

### Open issues

Lines that can only be covered by changing non-test code (listed, not
changed):

- `crates/commands/src/builtins/connector.rs` 704, 1204, 2384: the
  `resolved_ends(...)?` error arms — the resolver only ever answers
  `Ok` (a broken target degrades to a warning inside it).
- `crates/commands/src/builtins/connector.rs` 1239 and
  `crates/commands/src/builtins/connector_ends.rs` 113, 147: the
  `GlueEdit::new(...)?`/`resolved_ends(...)?` staging arms — their
  only failure sources (an unknown page, an out-of-range row index)
  cannot arise at these call sites.
- `crates/commands/src/undo.rs` 316 (a failed cancel always leaves
  un-reverted edits, so the fold block always runs) and 334 (`push`
  keeps `cursor == entries.len()`, so `entries.get_mut` cannot miss).
- `crates/commands/src/builtins/edit.rs` 421: `guarded`'s
  `Prior::Direct` with a non-`Direct` target — `stage` always pairs
  the two.
- `crates/commands/src/builtins/format.rs` 2392:
  `selection_targets` refuses an empty selection before the painter
  reads its first target.
- `crates/commands/src/builtins/clipboard.rs` 424: `paste_content`
