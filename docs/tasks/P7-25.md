## Why

The user's second manual pass (2026-10-31, at `514e45b`): there is no
way to add text to a shape, and the Text tool loses text, draws two
outlines and doesn't undo.

## Goal

4. **The Text Block tool** can be chosen with a text box or shape
   selected, and a drag moves and resizes the text block (`TxtPinX`,
   `TxtPinY`, `TxtWidth`, `TxtHeight`; one undo step per drag). Today
   `tools.text_block` has a `commands.yaml` row and no handler.
5. **The Text tool's icon** reads as a thumb. Replace it with a clear
   letter-A text icon from an open-licensed set (Tabler is the set
   already used), then run `cargo xtask codegen`.
8. **Adding text to a shape:** double-clicking a shape, typing a
   character with a shape selected, or pressing F2 starts editing its
   text, as in Visio. A typed character starts the text with that
   character.
9. **The Text tool:**
   - while editing, one outline shows, not both the text box's and the
     shape's;
   - Undo (Cmd+Z, Ctrl+Z, the button) removes a text object just made,
     with its text, in one step;
   - any click with the Text tool first commits the text being typed;
     a click inside an existing text object edits that object's text,
     and a click on empty page starts a new one (today the tool's
     `PointerUp` always inserts a new box, so a click inside the old
     object's border drops the typed text);
   - Escape ends editing and keeps the text.
