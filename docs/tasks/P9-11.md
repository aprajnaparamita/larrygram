## Goal

1. **Protocol tests** (`crates/control/tests/`): the golden
   transcripts for every control-protocol method, every MCP method and
   tool in both eras; the error table end to end (one request per
   `ErrorCode`); the socket handshake and auth (right, wrong, missing,
   late token; the discovery file's mode; the connection cap; the rate
   limiter); the policy through `commands/invoke` and `render/page`.
2. **Property tests**: arbitrary bytes through framing and
   `parse_message` never panic; `encode_op`/`decode_op` and the cursor
   round trips.
3. **The fuzz target** `crates/control/fuzz` (`request`): frames
   through `serve` with each front end over a headless backend with a
   small seeded document and small render caps; seeds from the
   transcripts. Build it with `cargo +nightly fuzz build` and run it
   locally for at least ten minutes; report the run in the Result.
4. **The end-to-end MCP flowchart** (`mcp_flowchart.rs`): the ADR 0082
   steps 1 to 6 against the built `larrygram-cli mcp` binary as a child
   process, in both eras. And `control_session.rs`: the same session,
   smaller, with `larrygram-cli serve` and the control protocol.
5. **The report** `docs/reviews/phase-9-tests.md`: what is covered,
   what is not, the fuzz run, the bugs found and fixed.
