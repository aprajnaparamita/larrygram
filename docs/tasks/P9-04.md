## Goal

1. **`Handles`.** Mint `"doc-<n>"` in open order on `sync`, keep a
   handle while its session stays open, never reuse a number; `handle`
   and `resolve` (`NotFound` for an unknown handle, `NoDocument` when
   nothing is open).
2. **Cursors and pages.** `encode_cursor`/`decode_cursor` (opaque, for
   example `"o:<offset>"`; anything else `InvalidParams`);
   `resolve_page` by index (1-based) or exact name.
3. **The views.** `document_info`, `list_documents`,
   `inspect_document`, `inspect_page` (filter, `recursive`, paging,
   connects touching the returned shapes, the caps and their
   `truncated` flags), `inspect_shape` (full text capped, the cells
   `cells` asks for: section names, `cells`, `all`; an unknown section
   name is `InvalidParams` listing the valid ones), `inspect_selection`.
   Effective values in inches and degrees, as ADR 0078 says; text cut
   on a character boundary.
4. **Tests.** Hand-built documents (pages, a group, an instance with an
   inherited size, a connector glued at both ends, a long text, a
   shape with cells in several sections) for every view, every filter
   field, paging across three pages of results, every refusal. One
   test over a corpus `.vsdx` file (skip cleanly when `corpus/` is
   absent, as the other corpus tests do) that inspects every page
   without error and stays within the caps.
