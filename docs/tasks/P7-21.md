## Goal

1. **Inventory** (in the Result): every format and arrange control of
   both committed layouts, with its command and status.
2. **Implement the basic set**, each a registry command with an
   enabled predicate, undo and a test, applied to the selection,
   reachable from both layouts:
   - Text: font family, size, bold, italic, underline, strikethrough,
     font colour, grow/shrink font, horizontal and vertical alignment,
     bullets off/on.
   - Fill: colour (a palette of theme and standard colours, plus
     no fill), transparency.
   - Line: colour, weight, pattern, arrowheads (begin and end), no
     line.
   - Arrange: align, distribute, group, ungroup, bring forward/to front,
     send backward/to back, rotate 90°, flip (check each is reachable
     and enabled).
   - Format Painter (copy and apply format).
   - The Page Setup dialog over P7-20's `page.setup` command (page
     size, orientation, units), in the P7-18 style.
   Each writes the ShapeSheet cells the renderer reads (the model's
   cells, recalculated by the ShapeSheet engine).
3. **Pickers** that look like the P7-18 design: open from the split
   buttons and menus, keyboard-navigable, close on choice or Escape.
4. Anything still a stub in these areas afterwards is listed with the
   reason.

## Result

**What changed**

- **The formatting commands** (`crates/commands/src/builtins/format.rs`,
  new; `arrange.rs` for the arrange additions; `mod.rs` registers them).
  Every command of the basic set is a registry command over the
  selection with an enabled predicate, one undo step and tests:
  - *Text*: `text.font`, `text.font.size` (points in, inches out),
    `text.font.size.increase`/`.decrease` and the Classic aliases
    `format.text.increase_size`/`decrease_size` (a size ladder),
    `format.text.bold`/`italic`/`underline` and
    `tools.strikethrough` (Classic's `text.strike.through` alias,
    toggles), `text.font.color` and `format.text_color.use_default`,
    `format.text.align_left|center|right|justify`,
    `format.text.align_top|middle|bottom`, `text.bullets`.
  - *Fill*: `format.set.fill.color`, `format.fill_color.no_fill`,
    `format.fill_color.use_default`, `shape.transparency` (and its
    dialog form `shape.transparency.dlg`),
    `format.transparency.no_transparency`.
  - *Line*: `format.set.line.color`, `format.line_color.use_default`,
    `format.line_color.no_line`, `format.set.line.weight`,
    `format.set.line.pattern`, `format.line_pattern.no_line`,
    `format.set.line.ends` (`begin`/`end`/`value`),
    `format.line_ends.no_line_ends`.
  - *Arrange*: `arrange.align.box` and `arrange.position` (the Panel
    Modern galleries' `value` forms), `arrange.align.center` (the
    box-centre alias), the four `arrange.distribute_shapes.*` ids,
    `arrange.rotate90.clockwise` and `arrange.object.rotate90`,
    `arrange.flip_horizontal` and `arrange.flip_vertical`; align,
    distribute, group, ungroup and the four z-order commands were
    already implemented (P5-09) and are checked reachable below.
  - *Format Painter*: `tools.format_painter` copies the anchor shape's
    format (its `AppCtx::format_painter` source) and applies it on the
    next run (or with the `apply` flag) as one undo step.

  Every run is one [`FormatEdit`]: it writes the cells the renderer
  reads (`Character` rows `Font`/`Size`/`Style`/`Strikethru`/`Color`,
  `Paragraph` rows `HorzAlign`/`Bullet`, `VerticalAlign`,
  `FillForegnd`/`FillPattern`/`FillForegndTrans`,
  `LineColor`/`LineWeight`/`LinePattern`/`BeginArrow`/`EndArrow`),
  creating a local `Character`/`Paragraph` row with `IX 0` when the
  shape inherits its rows (the row's other cells keep resolving through
  the master rung, ADR 0019), and reverts by restoring the captured
  sheets exactly. "Use default" removes the local entry, so the cell
  inherits again (ADR 0038's spelling of `Inh`). Colours are written as
  `RGB(r,g,b)` literals (the spelling the formula engine writes back
  unchanged); the picker values are `#RRGGBB`.

- **The pickers** (`crates/ui/src/pickers.rs`, new): the colour picker
  (theme and standard swatches, no fill / no line / use default, and
  the fill transparencies), the font family list, the font size box
  and ladder, the line weight and pattern lists and the arrowhead
  list, drawn in the P7-18 menu style (theme tokens, 22 px rows,
  the `menu.highlight.*` selection tint). Every choice is an `Intent`
  for a formatting command; the pickers execute nothing themselves.
  They open from the Panel Modern combos and splits and the Panel
  Classic toolbar splits (the hosting lines only); the arrow keys move
  the highlight and Enter chooses it (the classic menu rule), Tab
  reaches the rows as ordinary buttons, and Escape closes the host's
  popup.

- **The Page Setup dialog** (`crates/ui/src/page_setup.rs`, new) over
  P7-20's `tools.options.page.setup`: page size (width and height in
  inches), orientation and measurement units
  (`DisplayUnits::NAMES`), in the P7-18 dialog style
  (`theme::raise_controls`, the accent default button). OK
  re-dispatches the command with `width`, `height`, `orientation` and
  `units`; Cancel and the close button change nothing. `shell.rs`
  carries the one seam the master note allows (the `ShowPageSetup`
  match arm and the window that hosts the body).

- **`edit.redo.or.repeat`** registers as an alias of `edit.redo` (the
  Panel Modern Quick Access Redo).

- **Links** (`ui-spec/layouts/panel-modern.yaml`, three lines): the
  Line split's Weight, Dashes and Arrows lists carried no command, so
  their rows had nothing to dispatch; they link
  `format.set.line.weight`, `format.set.line.pattern` and
  `format.set.line.ends` now (linking only, the P7-20 rule).

### Open issues

- **The renderer draws no flip.** `arrange.flip_horizontal` and
  `arrange.flip_vertical` write the model's `FlipX`/`FlipY` cells (the
  spelling `Document::group_shapes` writes) and the connector router
  reads the flip, but `crates/render` ignores the cells, so a flipped
  shape draws unmirrored. Honouring `FlipX`/`FlipY` in
  `render::build_shapes` is a render-crate change.
- **Theme-linked colours are resolved colours.** The picker writes the
  theme hues as `RGB` literals; a swatch that stays *linked* to the
  document theme (`THEME(...)` / `THEMEGUARD`) needs the theme colour
  reference in the formula language first.
- **The classic font and size combos stay text boxes.** Visio's are
  combos with a drop-down list; the Panel Modern ones open the font
  family list and the size ladder, and the Classic ones take a typed
  value. A drop-down on the classic combos is a `toolbar.rs` change.
- **The Format Painter applies from the toolbar button or an
  invocation**, not yet from a click on the canvas (the canvas click
  path is `crates/ui/src/canvas.rs`, P7-19's file). The `apply`
  argument is the programmatic form.
- **The Page Setup dialog reads the page size from the page sheet's
  cached cells only** (no inherited or styled page sheet); a page whose
  size lives on its background gets the default Letter fields.
- **`arrange.position`'s value names** are our own (`distribute
  horizontal`, `distribute center`, ...): the committed `position`
  gallery list has no entries yet (`LiveLists`), so the names are what
  the future list rows will carry.
