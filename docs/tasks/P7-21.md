## Goal

1. **Inventory** (in the Result): every format and arrange control of
   both committed layouts, with its command and status.
2. **Implement the basic set**, each a registry command with an
   enabled predicate, undo and a test, applied to the selection,
   reachable from both layouts:
   - Text: font family, size, bold, italic, underline, strikethrough,
     font colour, grow/shrink font, horizontal and vertical alignment,
     bullets off/on.
   - Fill: colour (a palette of theme and standard colours, plus
     no fill), transparency.
   - Line: colour, weight, pattern, arrowheads (begin and end), no
     line.
   - Arrange: align, distribute, group, ungroup, bring forward/to front,
     send backward/to back, rotate 90°, flip (check each is reachable
     and enabled).
   - Format Painter (copy and apply format).
   - The Page Setup dialog over P7-20's `page.setup` command (page
     size, orientation, units), in the P7-18 style.
   Each writes the ShapeSheet cells the renderer reads (the model's
   cells, recalculated by the ShapeSheet engine).
3. **Pickers** that look like the P7-18 design: open from the split
   buttons and menus, keyboard-navigable, close on choice or Escape.
4. Anything still a stub in these areas afterwards is listed with the
   reason.
