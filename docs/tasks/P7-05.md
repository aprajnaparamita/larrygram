## Inputs

- ADR 0063 and `docs/ui/themes.md`.

  P7-03.

## Goal

1. **Apply a theme.** `theme::apply(ctx, &Theme)` sets egui `Style` and
   `Visuals` from the tokens, as mapped in `docs/ui/themes.md`, and
   registers Selawik (Regular, Light, Semibold) from `crates/text/fonts`
   as the proportional UI font.
2. **Token lookups.** `theme::color(&Theme, token)` and
   `theme::metric(...)` return a default for a missing token and warn
   once per token (never panic).
3. **Canvas colours.** The canvas reads `canvas.background`,
   `page.background`, `page.border`, `page.shadow` and the ruler
   colours.
4. **Switching.** Switching layout re-applies its theme on the next
   frame.

## Acceptance criteria

- [ ] Both themes apply. A test reads back the egui visuals for a few
      tokens.
- [ ] A missing token falls back and warns (test).
- [ ] The fonts load on native and on wasm.
- [ ] Hand-off gate green (`--quick` plus coverage and wasm).

## Result

Done. Rebased on `main` (clean; the three new commits touch only tools
and docs). Three commits on `agent/P7-05`:

- `feat(ui): apply theme tokens to egui and load Selawik` — new
  `crates/ui/src/theme.rs` replacing the P7-01 stub. `theme::apply(ctx,
  &Theme)` sets `Style`/`Visuals` per the mapping in
  `docs/ui/themes.md` (chrome fills and text, hovered/pressed button
  states, menus and popups, text-field backgrounds, the theme's named
  text styles) and registers Selawik Regular, Light and Semibold from
  `crates/text/fonts` (OFL) as the proportional UI font with per-style
  sizes. `theme::color` and `theme::metric`/`metric_field` return a
  fallback for a missing or malformed token and warn once per token via
  a process-wide set; they never panic. `theme::current(ctx)` records
  the active theme; switching layout calls `apply` again and the next
  frame reads the new colours.
- `feat(ui): read the canvas colours from the active theme` —
  `CanvasColors` in `crates/ui/src/canvas.rs` reads `canvas.background`,
  `page.background`, `page.border`, `page.shadow`, `ruler.background`
  and `ruler.ticks`, per-token fallback included.
- `docs(ui): fix the theme module's rustdoc links`.

Tests (in `theme.rs` and `canvas.rs`): both themes apply and the egui
