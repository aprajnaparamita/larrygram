## Goal

Review the Phase 9 code for correctness, error handling, API design,
idiomatic Rust, dead code and duplication, with these in particular:

- **Hostile input**: every path from a frame to the executor; caps
  checked before the allocation they guard; no panic path (`unwrap`,
  indexing, unchecked arithmetic, unbounded recursion) in non-test
  code.
- **Threads**: the inbox, the listener and the connection threads: no
  deadlock when the app quits mid-request, no thread left running
  after `stop`, timeouts honoured.
- **The policy**: every path argument checked, symbolic links and
  `..` resolved, the extension rule and `overwrite` enforced, the
  remote-access rule applied before dispatch, nothing written outside
  the roots by any command (read the command handlers too).
- **One implementation**: the front ends contain no feature logic; no
  second list of commands anywhere (master note of P9-01).
- **The protocols**: the wire matches ADR 0075 and the MCP 2026-07-28
  and legacy shapes ADR 0080 names; stdout carries only protocol
  messages.
- **The attached app**: remote dispatch through the shell, undo
  recorded, UI requests not acted on, `Busy` when it should be.
