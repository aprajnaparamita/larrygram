### What changed

Every blocker and major finding of the three audits is fixed, each in
its own commit with a test; the report's "The audits, and what P7-14
did about them" table maps finding to fix to commit. In brief:

- **P7-11 F1 (theme tokens, master's ruling: ADR 0063 stands).** The
  widgets now read their colours and sizes by token name
  (`theme::color_at`, a new `panel_classic::metrics::ClassicMetrics`
  beside the Panel Modern `Metrics::from_theme`): menu highlight and
  open menu bar, separators, gutters, panes, status bars, tabs, page
  tabs, groups, the File view, the contextual tab sets and every Panel
  Classic metric. Both theme files carry the full widget vocabulary
  (the classic menu widget draws every context menu and the shell runs
  both metric readers against the active theme). New test
  `every_theme_token_is_read_by_a_widget` fails when a theme token is
  read by no widget. The goldens regenerated in the same commits and
  were reviewed each time. **Tokens deleted** (no surface draws them):
  `scroll.track` (egui paints its own scroll bars; the seam cannot ask
  for the token) and `icon.large` (no Panel Classic surface draws a
  32 px icon).
- **P7-11 F2 (disabled icons):** 40% alpha through
  `icons::draw(..., enabled)` and the `icon_themed` callers, asserted
  on a rendered icon in both states.
- **P7-11 F3/F4/F5:** the stale comments rewritten, ADR 0066 amended
  (Cancel keeps the current layout), `docs/ui/panel-classic.md`'s
  context-menu table marks every target routed or pending.
- **P7-11 F6:** the welcome row dispatches `help.welcome.next_start`
  with its `show` argument; every user action is a command.
- **P7-12 majors 1-10:** the Help menu click, the file-dialog spec,
  the failing-command status line (the error now shows in every
  layout, not only the Phase 4 one), the toolbar popup chains, the
  `value` dispatch arguments, the "All" page menu, the 2016/365
  backstage pages, the routed right-click targets, the hand-written
  known-menu fixture and the label-fit width assertion (the labels
  stopped wrapping one letter per line).
- **Master notes:** the File menu's labels read from the theme (they
  were nearly invisible), the solid dark icon squares are the 40%
  alpha icons now, the QAT customise menu opens (a display-only menu
  opener draws enabled whatever its command says) and the floating
  toolbars open below the docked rows with a golden at the defaults.

### Deviations

1. **F6 reached three files outside the strict ownership list**, all
   forced by the command-registry contract: `crates/commands`
   (`help.welcome.next_start`'s builtin and its undo classification),
   `xtask/src/extract/commands.rs` (the `OUR_COMMANDS` row, so the
   next `xtask extract` keeps it) and `ui-spec/commands.yaml` (the
   row; the count pin moved to 1128 in `crates/ui-spec/tests/`).
   `docs/parity/controls.md` regenerated with `cargo xtask parity`.
2. `crates/ui/src/panel_classic/metrics.rs` is a **new public module**
   (the gate's doc step rejects public docs linking a private type);
   `panel_modern::measure_widths` is public for the width assertion.
3. The window goldens changed on purpose several times (the theme
   wiring, the label wrap, the contextual caption position) and one
   golden was added (`panel-classic-floating-toolbars.png`).
4. The rulers draw at the `ruler.size` token (16 px), where the old
   constant was 18 px: the Phase 5 test mirrors moved with it.
