## Master rulings (2026-10-25)

- **P7-11 F1, the theme tokens: ADR 0063 stands.** Widgets read their
  colours and sizes from the theme by token name. Wire the tokens the
  report lists where they are drawn (menu highlight and open menu bar,
  separators, gutters, panes, status bar, tabs, page tabs, groups, the
  File view, the contextual tab sets) and take every Panel Classic
  metric from the theme as `Metrics::from_theme` does for Panel Modern.
  Delete a token only when no surface draws it, and say which in the
  Result. Add a test that fails when a theme token is read by no
  widget. The goldens change on purpose in the same commits; look at
  each one.
- **P7-11 F2, disabled icons:** fix as the report says (40% alpha
  through `icons::draw(..., enabled)` and the `icon_themed` callers),
  with an alpha assertion.
- **P7-11 F3 and F5:** fix (stale comments; mark the unrouted
  right-click targets in `docs/ui/panel-classic.md` as pending, or
  route them).
- **P7-11 F4:** the code is right. Amend ADR 0066: Cancel keeps the
  current layout (Panel Modern on a first launch, where it is the
  default).
- **P7-11 F6:** give the "show the welcome wizard on next start" row a
  command id, like every other Options row (AGENTS.md section 6 has no
  exception). Settings changes carry no undo, as for the other rows.
- **P7-12:** fix every major finding (tests that assert outcomes
  rather than mirror the widget rules, dispatch arguments, rendered
  placement, the Panel Modern Help menu, the file picker path, the
  shell's error arms, the toolbar popup hover, the 2016/365 File view,
  the unreachable contexts). Minor findings where the change is small.
