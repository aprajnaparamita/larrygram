## Goal

One endpoint resolution rule, used by `connector.draw`, `connector.glue_*`,
`connector.unglue` and every re-route, so a connector end lands where
the user dropped it and stays put across passes:

- Point glue resolves to the named `Connection` row's point through
  the target's page transform (unchanged).
- Dynamic glue resolves to the `Connection` row point nearest the
  other end's resolved point (ties: the lower row `IX`); a target with
  no rows falls back to the nearest point of its page-space bounds.
- An unglued end resolves to its own last geometry point and never
  drifts on unrelated re-routes.
- Resolution order: static ends first (point glue and free ends are
  fixed points), then dynamic ends against the other end's resolved
  point; a dynamic end facing another dynamic end uses the other
  end's target centre as origin.
- Glue record spellings stay the documented ones (spec section 8):
  `ToCell` `Connections.X<n>` / `ToPart` 100 + ix for point glue,
  `ToCell` `PinX` / `ToPart` 3 for dynamic glue.

## Interfaces

```rust
// crates/geom/src/glue.rs (L0, pure geometry, inches)

/// The page-space facts one glue target offers.
pub struct GlueTarget<'a> {
    /// The target's `Connection` rows as `(row IX, page-space point)`.
    pub points: &'a [(i32, Point)],
    /// The target's page-space bounds (the local box through its transform).
    pub bounds: Rect,
}

/// What a `Connect` record names on the target (ADR 0084 rule 1).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum GlueEnd {
    /// A `Connection` row `IX` (point glue).
    Point(i32),
    /// The shape itself (dynamic glue).
    Shape,
}

/// Resolves one glued end to a page-space point (ADR 0084 rule 2).
///
/// Point glue: the named row's point, falling back to the dynamic rule
/// with one warning when the row is gone. Dynamic glue: the row point
/// nearest `origin` (lower `IX` breaks ties), else the nearest point
/// of `bounds` to `origin`. Never panics; non-finite inputs fall back
/// to the bounds' nearest point or the bounds centre.
pub fn resolve_glued_end(target: &GlueTarget<'_>, end: GlueEnd, origin: Point) -> Point;

/// The nearest point of `bounds` to `origin` (clamping outside,
/// nearest-edge projection inside). Replaces `nearest_on_rect` in
/// `crates/commands/src/builtins/connector.rs`.
pub fn nearest_point_on_bounds(bounds: Rect, origin: Point) -> Point;
```

`crates/commands/src/builtins/connector.rs` drops its local
`nearest_on_rect` and calls `larrygram_geom::glue`. `resolved_end` and
`reroute_document` share one helper that computes both ends in the
resolution order above; `glue_record` and `connection_index` keep
their spellings.
