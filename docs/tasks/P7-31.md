## Goal

1. **A 1-D connector master** (ADR 0084 rule 1). Rebuild the "Connector"
   master: the endpoint cells, the pin, size and lock formulas,
   `ObjType` 2, `GlueType` 2, `ShapeRouteStyle` 1, `ConLineRouteExt` 1,
   the two triggers, one straight geometry path, and **no connection
   points**. Keep the master's name and its place in the stencil.
   Write it as our own master: no help topic, no copyright string, no
   cells the alpha does not use.
2. **Path writes keep the 1-D cells true.** `write_connector_path`
   writes `BeginX`/`BeginY` from the first point and `EndX`/`EndY` from
   the last, refreshes `PinX`, `PinY`, `Width` and `Height` and the
   local pins through the formulas (recalc) or their values, and writes
   the geometry rows in the box's local coordinates. A connector drawn
   right to left (negative `Width`) renders on the same pixels as the
   same connector drawn left to right, and it hit-tests and selects
   the same way. No panic, no mirrored drawing.
3. **Glue formulas** (ADR 0084 rule 2, the table). Every glue, re-glue
   and unglue (`connector.draw`, `connector.glue_begin`,
   `connector.glue_end`, `connector.unglue`) writes the end's
   formulas, cached values and trigger as well as the `Connect`
   record, in one undoable edit. A re-glue replaces formulas Visio
   wrote. Deleting a glue target clears the formulas of the ends glued
   to it, leaving each end's last point as a literal, and drops the
   records, in the same edit as the delete.
4. **Visio-owned functions.** `PAR`, `PNT`, `_WALKGLUE` and
   `_XFTRIGGER` keep their cached value in recalc. They produce no
   warning, no error and no `UnknownFunction` entry. A corpus file with
   glued connectors (`corpus/vsdx/testfile3.vsdx`) opens, recalcs and
   saves with every endpoint formula and value unchanged.
5. **Right angle by default** (ADR 0084 rule 8). `connector_style` and
   `style_from_value` fall back to right angle where they fall back
   to straight today: for a missing or 0 cell, a missing page value,
   16, the directed values and unknown values. A newly drawn
   connector routes right angle.
6. **`is_connector`.** Use `Document::is_connector` wherever the
   commands crate asks "is this a connector". A shape that is the
   `FromSheet` of a glue record but has no endpoint cells keeps
   re-routing as today.

## Interfaces

```rust
// crates/model/src/connector.rs (new)

/// Which end of a 1-D shape.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ConnectorEnd {
    /// `BeginX`/`BeginY`.
    Begin,
    /// `EndX`/`EndY`.
    End,
}

/// What one connector end is glued to, as ADR 0084 rule 2 stores it.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum EndGlue {
    /// Point glue to the connection row with zero-based index `ix` of
    /// the shape whose Visio `ID` is `sheet`.
    Point { sheet: i32, ix: u32 },
    /// Dynamic glue to the shape whose Visio `ID` is `sheet`.
    Dynamic { sheet: i32 },
    /// Unglued.
    Free,
}

impl Document {
    /// True when `shape` has the four 1-D endpoint cells, its own or
    /// inherited from its master (ADR 0084 rule 1).
    pub fn is_connector(&self, shape: ShapeId) -> bool;

    /// The page-space point of one end, from its endpoint cells.
    pub fn connector_end(&self, shape: ShapeId, end: ConnectorEnd) -> Result<Point, Error>;

    /// Writes one end's endpoint cells (formula and cached value at
    /// `at`, page inches) and its trigger for `glue`, replacing any
    /// formula already there. It does not touch the `Connects`
    /// records; the caller writes them in the same edit.
    pub fn write_connector_end(
        &mut self,
        shape: ShapeId,
        end: ConnectorEnd,
        at: Point,
        glue: EndGlue,
    ) -> Result<(), Error>;
}
```

`write_connector_path` keeps its signature. Use the existing
`write_cell` / `CellWrite` primitives; add no second path for writing
cells.
