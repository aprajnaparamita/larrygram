## Goal

- The user can set the routing style of a connector (right-angle,
  straight, curved) and the default for new connectors, through the
  command registry (`connector.style`), and the choice is stored:
  - per connector: `ShapeRouteStyle` (1 = right angle, 2 = straight)
    and `ConLineRouteExt` (1 = straight, 2 = curved), the documented
    cells (spec section 5);
  - as the page default: the page sheet's `RouteStyle` cell; a
    connector without a local style follows it.
- Reading a file: the three cells map onto our `RouteStyle` values;
  the directed styles (org chart, flowchart, tree, network) are
  preserved as cached cell values but render as right-angle.
- Storage parity, verified by tests: every glue kind we write (point,
  dynamic) uses the documented `Connects` spellings and round-trips
  through save and open unchanged; the round-trip test runs on real
  corpus files and on documents our tools build.

    pub const ROUTE_STYLE: &str = "RouteStyle";

}

/// Maps the three cells onto our `RouteStyle`, page default first
/// (`shape_cells` is the connector's sheet cells, `page_cells` the

/// The cells one `connector.style` run writes for a style choice.
