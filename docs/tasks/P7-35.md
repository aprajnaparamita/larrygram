## Goal

1. **Midpoint handles.** A selected right-angle connector (route style
   right angle, not curved) shows a midpoint handle on each segment.
   Straight and curved connectors show none.
2. **Segment drags.** Dragging a midpoint handle moves that segment
   perpendicular to itself and stretches the two neighbours.
   - An end segment (one touching a connector end) gets a new bend
     inserted, so the end stays where it is glued.
   - The route stays axis-aligned, keeps its ends, and repeats no
     point.
   - The result is written as the connector's geometry, as one
     undoable `connector.move_segment`.
3. **The stored route is the memory** (rule 5). A moved segment
   survives an unrelated edit, a save and reopen, and undo and redo.
   It is replaced by a fresh route only when P7-32's scoped re-route
   picks that connector, because a glued shape changed.
4. **Reset Connector.** `connector.dyn.conn.reroute`, from the
   connector context menu in both layouts and from Panel Classic's
   Layout & Routing toolbar, re-routes the selected connectors fresh.
   It is disabled with no connector selected.
5. **Reroute options** (Panel Classic, Layout & Routing).
   `format.set.dyn.conn.reroute.freely`,
   `format.set.dyn.conn.reroute.on.crossover` and
   `format.set.dyn.conn.reroute.never` write `ConFixedCode` 0, 3 and 2
   on the selected connectors and show the current value checked.
   - With Never, the scoped re-route keeps the connector's interior
     points; only its ends follow their glue, and the end segments
     stretch to reach them.
   - The other values behave as rule 5.

## Interfaces

```rust
// crates/geom/src/routing.rs (added)

/// Moves segment `index` of an axis-aligned `path` to `to` along its
/// normal (x for a vertical segment, y for a horizontal one),
/// stretching its neighbours. An end segment gets a new bend so the
/// path's first and last points stay. Returns the new path; never
/// panics. A non-axis-aligned segment or an index out of range is
/// `Error::InvalidArgument`.
pub fn move_segment(path: &[Point], index: usize, to: f64) -> Result<Vec<Point>, Error>;
```

```rust
// crates/commands/src/builtins/connector_segments.rs

/// `connector.move_segment`: args `connector` (Visio id), `segment`
/// (index in the current path), `to` (page inches). One undoable edit.
pub(crate) fn run_move_segment(ctx: &mut AppCtx, inv: &Invocation) -> Result<Outcome, CommandError>;
```
