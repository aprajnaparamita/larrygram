## Goal

Implement the About window of ADR 0066 in `crates/ui/src/about.rs`:

1. **Layout.** Left half `larry.png` scaled to fit; right half with
   generous padding and the dedication text exactly as in ADR 0066;
   **[ Watch Larry's story ]** centred; **Close** at the bottom.
2. **The video button.** It returns `Outcome::WatchVideo`, and the
   caller opens `about::VIDEO_URL` through egui's open-URL output,
   which works on desktop and on web. The `?si=...` tracking id stays
   out.
3. **The app icon.** `icon.svg` becomes the desktop window icon (the
   eframe/winit icon API) and the web favicon (`<link rel="icon">` in
   `apps/larrygram-web/index.html`). One SVG source; no raster copy
   is committed.
4. **Images.** `larry.png` loads through the ADR 0067 loader: R5 put
   it in `main`, so embed the bytes and draw them with `egui::Image`.
   Tests call `larrygram_ui::install_image_loaders` on the harness
   context first. The desktop window icon needs RGBA pixels before the
   first frame: rasterise `icon.svg` in `apps/larrygram` with the
   `resvg` 0.45 already in the tree (add it to
   `apps/larrygram/Cargo.toml`; you own that file for this). Keep the
   `install_image_loaders` call in both apps' start-up closures.
