# R6: Remove Microsoft sample content from git history

- Role: master (the master runs this task itself; it rewrites `main`)
- Phase: the boundary between Phase 8 and Phase 9
- Depends on: the Phase 7 and Phase 8 gates passed, every worker
  handed off and merged, no gate queued or running. Runs before the
  user's manual test of the macOS build and before R7 (the `.dmg`).
- Parallel-safe with: nothing. No worker may run while history is
  rewritten.

## Why

P8-13 (F1) found that a committed golden,
`crates/render/tests/golden/vsd/tdf76829-datetime-format-p1.png`,
renders a Microsoft sample drawing in full: a stock-template timeline
for Microsoft's sample company, with its long-form sample text.
AGENTS.md section 4 forbids committing Microsoft-owned content, and
ADR 0005 keeps such drawings out of the repository, history included.
P8-17 deletes the golden going forward; earlier versions remain in
history.

## Paths to remove from every commit

- `crates/render/tests/golden/vsd/tdf76829-datetime-format.png`
  (P8-10)
- `crates/render/tests/golden/vsd/tdf76829-datetime-format-p*.png`
  (P8-15)
- Any path a later clean-room audit adds here before this task runs.

## Steps

1. **Check that nothing runs.** `git worktree list` shows only the
   main checkout and `main-full`; `gateq status` shows no running or
   queued job; every `agent/*` branch is merged into `main`.
2. **Sweep once more.** Look at every committed PNG under
   `crates/*/tests/golden/` and every snapshot for sample content
   (stock-template drawings, sample company names, long-form text).
   Add any hit to the list above.
3. **Back up.** `git bundle create
   /Volumes/Dara/larrygram/backup/pre-R6.bundle --all`, and verify it
   (`git bundle verify`).
4. **Rewrite.** `git filter-repo --invert-paths` with one `--path`
   (or `--path-glob`) per entry above, on a fresh clone of the main
   repository, as in R4.
5. **Verify.** `git log --all -- <each path>` prints nothing; the
   commit count and every tag survive (the tags move to their
   rewritten commits); `cargo xtask gate` (full, with the corpus) is
   green on the rewritten `main`.
6. **Replace.** Swap the rewritten repository in for the main
   checkout, recreate `main-full`, delete the merged `agent/*`
   branches and their worktrees.
7. **Hand over the push.** The user force-pushes; the master never
   pushes. After the user confirms the push, the old backups
   (`pre-r4.bundle`, `old-vm.bundle`, `filter-repo-2026-10-13`, and
   later `pre-R6.bundle`) are deleted only on the user's word.
