## Why

Before the alpha release the user runs one manual pass over the
installed Mac app. They want a simple page of checkboxes that
remembers what they ticked. The master publishes the page as a
private web page for the user; this task writes it.

## Goal

One self-contained HTML file: a checklist the tester ticks while
testing.

1. **State.** Checkboxes and notes are saved in `localStorage` under
   the key `larrygram-alpha-checks-v1`, so they survive reloads. Wrap
   every `localStorage` read and write in `try`/`catch`; the page must
   work, without persistence, when storage throws or is empty.
2. **Header.** The title "Larrygram Alpha Checks", a line "Build
   ab93811 · 5 Nov 2026 · macOS", and a live progress line ("23 of 61
   checks passed"), counting boxes.
3. **Rows.** Each row has the check text, then its boxes. A row marked
   `[M,C]` gets two checkboxes labelled "Modern" and "Classic" (the two
   UI layouts, Panel Modern and Panel Classic); a row marked `[one]`
   gets one checkbox labelled "Pass". Each row also has a small
   optional one-line notes input, saved too. Every checkbox and input
   has a stable id derived from the row's id. Rows are grouped in the
   sections below, each with a heading and its own "n of m" count.
4. **Copy results.** A button that copies a plain-text report to the
   clipboard: the overall count at the top, then each section and each
   row as `[x]`/`[ ]` per box, plus its note if any. Call
   `navigator.clipboard.writeText` inside the click handler, catch the
   rejection, and fall back to showing the report in a read-only,
   selected textarea. Show a short status: "Copied", or "Select the
   text below and copy it".
5. **Clear all.** A button with an in-page two-step confirm: the first
   click turns it into "Click again to clear", which reverts after 4
   seconds. `alert()`, `confirm()` and `prompt()` do not work where the
   page is shown: never use them.

## Page rules (the viewer that shows the page sets these)

- No `<!doctype>`, `<html>`, `<head>` or `<body>` tags: the viewer
  wraps the file. The file starts with
  `<title>Larrygram Alpha Checks</title>`, then
  `<meta name="claude:viewport-fit-sides" content="cover">`, then one
  `<style>` block, the markup, and one inline `<script>` at the end.
- No external scripts or libraries. At most two Google Fonts, linked
  with `<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=...&display=swap">`
  and with real fallback stacks; otherwise system fonts. Not Inter, not
  Space Grotesk.
- Colours as CSS custom properties. Light values on bare `:root`; the
  dark values redefined in both
  `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { …; color-scheme: dark } }`
  and `:root[data-theme="dark"] { …the same dark values…; color-scheme: dark }`.
  `body` sets `background: var(--bg); color: var(--fg)`. No literal
  colours in component rules. A slightly blue-tinted neutral palette
  with one blue accent (the app icon is blue shapes on white); checked
  boxes clearly visible in both themes (`accent-color: var(--accent)`).
- Do not set padding on `:root` (the viewer pads it). The side gutter
  goes on one outer wrapper:
  `padding-left: max(16px, env(safe-area-inset-left, 0px)); padding-right: max(16px, env(safe-area-inset-right, 0px));`
  with vertical padding through `padding-block`. Content at most about
  860 px wide, centred.
- Works at 400 px width with no sideways page scroll: at narrow widths
  the boxes wrap under the check text. Flex or grid with `gap`; text
  containers get `min-width: 0`.
- Visible keyboard focus; each checkbox wrapped in its `<label>`.
  `font-variant-numeric: tabular-nums` on the counts. No animation.
- Plain and polished: no hero, no emoji, no "01/02" markers, no shadow
  on every block. Use the check texts below as written, except for
  typo fixes. Keep the ⌘ and ⇧ symbols.

## The checks

**Install and launch**
- [one] Open the .dmg and drag Larrygram to Applications. The first launch needs right-click > Open (the app is not notarized).
- [one] The Dock icon is the blue diagram on a white rounded square.
- [one] The welcome wizard appears on first launch, lets you pick a layout, and does not appear again on the next launch.
- [one] Switching between Panel Modern and Panel Classic redraws the window in the other layout.

**Files**
- [M,C] New drawing, add a few shapes, Save As .vsdx, close, reopen: everything comes back.
- [one] A .vsdx made in Visio opens and looks recognisably right.
- [one] A binary .vsd opens (read-only import); saving offers .vsdx.
- [one] Double-clicking a .vsdx in Finder opens it in Larrygram.
- [one] Quitting with unsaved changes asks to save; Save, Don't Save and Cancel each do what they say.

**Shapes**
- [M,C] Drag shapes from Basic Shapes and Basic Flowchart onto the page.
- [M,C] Select, move, resize from the handles, and rotate with the rotate handle.
- [one] Arrow keys nudge the selection; Shift+arrow nudges by one pixel.
- [M,C] Copy, paste, duplicate and delete.
- [M,C] Group and ungroup; a group moves as one shape.
- [M,C] Undo (⌘Z) and redo (⇧⌘Z) each of the above; the Undo list names the steps.

**Text**
- [M,C] Double-click a shape, type, click away: the text stays, centred in the shape.
- [M,C] The Text tool draws a text box you can type into.
- [M,C] Bold, italic, underline, font size and alignment change the selected text.

**Formatting**
- [M,C] Fill colour, line colour, line weight, dash pattern and arrowheads apply to the selection.
- [M,C] Format Painter copies one shape's format onto another.

**Connectors**
- [M,C] Connector tool: drag from inside one shape to inside another. The ends attach to the facing sides, on the outline (try a triangle, a diamond and a star).
- [M,C] Drag a connector end onto a connection point: the point highlights and the end attaches there.
- [M,C] Move a glued shape: the connector follows and re-routes.
- [M,C] Drag a connector end off a shape (it detaches), then onto another shape (it attaches).
- [M,C] Right angle, Straight and Curved styles from the context menu or Design > Connectors.
- [one] On a right-angle connector, drag a segment's midpoint handle; right-click > Reset Connector (Panel Classic) restores a fresh route.
- [one] Never Reroute (Panel Classic, Layout & Routing): moving a glued shape keeps the connector's bends.
- [one] Save and reopen a drawing with connectors: moving a shape afterwards still moves its connectors.

**Connection points**
- [M,C] View > Connection Points shows every shape's points, and turns them off again.
- [M,C] Connection Point Tool: click a shape to select it (outline and points show); drag a point to move it, and a connector glued to it follows.
- [M,C] ⌘-click on the selected shape adds a point; select a point and press Delete to remove it.
- [M,C] Right-click a point to set Inward, Outward or Inward & Outward.

**View and pages**
- [M,C] Zoom in, zoom out and Fit to Window; scroll and pan around the page.
- [M,C] Add, rename, switch between and delete pages.
- [one] The Shapes window search finds a shape by name.
- [one] Help > About shows the version and Larry's photo.
