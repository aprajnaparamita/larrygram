## Goal

1. **`schema.rs`.** `ArgSpec`, `ArgKind` (with `Choice` and the
   numeric ranges), `RemoteAccess`, as ADR 0077 writes them, documented
   and re-exported from `lib.rs`.
2. **The trait.** `Command::args(&self) -> &'static [ArgSpec]` and
   `Command::remote(&self) -> RemoteAccess` as provided methods
   (defaults: `&[]`, `Allowed`). `StubCommand` keeps the defaults; the
   builtins answer from one table keyed by id in `schema.rs`.
3. **Declare every implemented command.** One entry per implemented id
   (88 on 2026-10-25, more if Phase 7 or 8 work added some), with every
   argument its handler reads: kind, required, a one-line description
   in our own words, choices and ranges where the handler checks them.
   `app.quit` and `file.exit` are `HeadlessOnly`; `tools.agent_control`
   is `Never`; anything else you mark needs a reason in your Result.
4. **The completeness tests.** (a) every implemented command has a
   schema entry; (b) every argument name a handler reads is declared
   (choose a mechanism that is complete: for example a test that
   scans the builtin sources for `args.<kind>("<name>")` and
   `args.get("<name>")` reads per handler table, or a recording `Args`
   wrapper; say which in the Result); (c) a declared `Choice` lists
   exactly the values the handler accepts.
5. **The new commands.** `file.activate` (`document`: integer, the
   1-based position in open order; makes it active; refuses an index
   out of range with `InvalidArgs`), `page.go` (`page`: a 1-based index
   or `name`: a page name; makes it the active page and refreshes the
   selection's page), `tools.agent_control` (toggles
   `Settings::agent_control`, default false, persisted with the other
   settings, and returns a new `UiRequest::AgentControl { enabled }`
   variant the app acts on; the variant is `#[non_exhaustive]`-safe).
   All three through the extractor's own-commands list, with
   `cargo xtask codegen` run and its output committed.
6. **`SessionId::get(self) -> u64`.**
