## Goal

1. **Window regions.** Build the frame from the active layout's
   `window.regions`:
   - Panel Classic: menu bar, toolbars, Shapes window, page tabs and status
     bar.
   - Panel Modern: title bar with QAT, tab strip, command bar, Shapes window, page
     tabs with All and ⊕, and the status bar with zoom controls.
2. **Switching between four layouts**:
   - commands, the Options dialog radios and `--ui-layout
     panel-modern|panel-classic|panel-2016|panel-365`;
   - `Settings` default `panel-modern` for new stores;
   - stored values are kept;
   - no restart.
3. **Per-layout state.** Toolbar visibility for each Panel Classic window
   mode, the collapsed command bar flag and the last core tab are kept in
   `Settings` (serde defaults, so old stores still load).
4. **Wiring.** Route right-clicks through `contexts::menu_for`, the
   current context into the command bar, and window-mode changes into the
   Panel Classic menu bar.
5. **First run and Help.** The wizard opens on the first launch
   (`welcome_seen: false`, ADR 0066): host `wizard::show` before any
   document, apply `Outcome::Start` / `Outcome::Cancel`, and set
   `welcome_seen`. **Help > About Larrygram** and **Help > Welcome**
   open the About window and the wizard in every layout (Panel Classic
   carries the items in its Help menus; Panel Modern takes them from
   the title-bar help button's menu). Options gains "Show the welcome
   wizard on next start", which clears `welcome_seen`.
6. **Settings.** Move `welcome_seen` and the default layout from
   `crates/ui/src/settings.rs::WelcomeSettings` (the P7-01 stub) onto
   `larrygram_commands::Settings`, with serde defaults, and delete the
   stub. Keep `default_layout` and the active `ui_layout` in step.

## Master notes

P7-02 to P7-08, P7-15 and P7-16 are merged (master, 2026-10-25).
Their Result sections leave these to the shell; read each one before
you start, and list in your Result which you closed and which you
deferred.

- **Drawing the curated layouts** (P7-03). `LayoutSets::get` answers
  `None` for Panel Modern and Panel Classic, so today's shell draws no
  v1 widget for them (`a_curated_layout_kind_draws_no_v1_widgets` pins
  it). Draw those kinds from `ui_spec::v2` (the `panel_modern` and
  `panel_classic` fields, or `v2::load_layout`), give 2016 and 365
  their v2 form through `v2::from_v1`, and drop the `Option` from
  `get`. The `get` change is the one edit you may make in
  `crates/ui-spec` (it is in `src/lib.rs`); update the test that pins
  it. Rewrite the shell test to pin the new behaviour.
- **The widgets** (P7-06, P7-07). `panel_classic` and `panel_modern`
  draw against hand-built inputs. Wire in:
  - the loaded layouts;
  - the theme tokens (P7-05 `theme::apply` with the loaded
    `ui_spec::v2::Theme`, and `Metrics::from_theme` for Panel Modern);
  - the icon atoms with theme tints (P7-04 `icons::icon_atom`; both
    widget sets still paint `icons::icon` placeholders);
  - the list providers (`crate::lists`: recent files, windows, pages).
- **Dialogs behind commands** (P7-07). File view Browse, Print and
  Export dispatch `file.open`, `file.save_as`, `file.print` and
  `file.export`; the shell gives those their dialog behaviour, as it
  does for the command bar today.
- **Settings** (P7-06, P7-08, Goal 3 and 6). The Panel Classic toolbar
  visibility per window mode (kept today in `PanelClassic`'s own state
  under `"<mode>/<toolbar id>"` keys), the collapsed command bar flag
  and the last core tab go on `Settings` with serde defaults. P7-08's
  18 `on_by_default` toggles have no `Settings` or `ViewState` rows:
  add them only if your wiring needs them, otherwise list them as
  deferred.
- **The wizard and About** (P7-02, P7-15, P7-16).
  - `UiRequest::ShowWelcome` hits a wildcard arm in `shell.rs`: open
    the wizard there.
  - Apply `wizard::Outcome::Start { default_layout }` and
    `Outcome::Cancel` as ADR 0066 says.
  - `about::show` returns `Outcome::WatchVideo`: open
    `about::VIDEO_URL` through egui's open-URL output. On
    `Outcome::Close`, hide the window.
