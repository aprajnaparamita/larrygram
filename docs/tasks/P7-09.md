## Goal

1. **Window regions.** Build the frame from the active layout's
   `window.regions`:
   - Panel Classic: menu bar, toolbars, Shapes window, page tabs and status
     bar.
   - Panel Modern: title bar with QAT, tab strip, command bar, Shapes window, page
     tabs with All and ⊕, and the status bar with zoom controls.
2. **Switching between four layouts**:
   - commands, the Options dialog radios and `--ui-layout
     panel-modern|panel-classic|panel-2016|panel-365`;
   - `Settings` default `panel-modern` for new stores;
   - stored values are kept;
   - no restart.
3. **Per-layout state.** Toolbar visibility for each Panel Classic window
   mode, the collapsed command bar flag and the last core tab are kept in
   `Settings` (serde defaults, so old stores still load).
4. **Wiring.** Route right-clicks through `contexts::menu_for`, the
   current context into the command bar, and window-mode changes into the
   Panel Classic menu bar.
5. **First run and Help.** The wizard opens on the first launch
   (`welcome_seen: false`, ADR 0066): host `wizard::show` before any
   document, apply `Outcome::Start` / `Outcome::Cancel`, and set
   `welcome_seen`. **Help > About Larrygram** and **Help > Welcome**
   open the About window and the wizard in every layout (Panel Classic
   carries the items in its Help menus; Panel Modern takes them from
   the title-bar help button's menu). Options gains "Show the welcome
   wizard on next start", which clears `welcome_seen`.
6. **Settings.** Move `welcome_seen` and the default layout from
   `crates/ui/src/settings.rs::WelcomeSettings` (the P7-01 stub) onto
   `larrygram_commands::Settings`, with serde defaults, and delete the
   stub. Keep `default_layout` and the active `ui_layout` in step.
