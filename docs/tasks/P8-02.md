## Inputs

- ADR 0068 (the decision this task implements), ADR 0071 (errors,
  warnings, limits), ADR 0003 (MPL confinement).
- The Microsoft Open Specifications: MS-CFB, the OLE compound file
  format (allowed source; record the source under Open issues, the
  master adds the `docs/sources.md` row).
- The corpus: `corpus/vsd/*.vsd` (five files, all OLE compound files
  with `VisioDocument`, `\x05SummaryInformation` and
  `\x05DocumentSummaryInformation`; two also have `VisioInformation`).
- The libvisio reference for the compressed-block format (AGENTS.md
  section 5): the decompressor is derived code and belongs in this
  crate with MPL headers.

## Goal

1. **`read_streams`.** Implement the MS-CFB reader clean-room from the
   specification: header, FAT and mini-FAT chains, directory entries,
   stream bytes. Cycle-safe chain walks (visited set), checked
   arithmetic, `get()` indexing, and every `Limits` cap checked before
   the allocation it guards. Non-compound input is
   `Error::NotAVisioFile`; structural damage is `Error::Invalid` or
   `Error::LimitExceeded`, never a panic.
2. **`decompress`.** Implement the compressed-block decompression of
   the Visio stream format, capped by output size and expansion ratio
   (ADR 0068).
3. **Stream helpers.** Keep `Streams::get` and `Streams::visio_document`
   as they are; add what the chunk reader will need (for example a
   summary-stream decoder for `Document::properties`), all in your two
   files.
4. **Tests.** Malformed containers (bad signature, truncated header,
   FAT and mini-FAT cycles, lying sizes, oversized streams),
   decompression round trips and bomb caps, and a corpus smoke test:
   the five files open and their `VisioDocument` streams start with the
   Visio magic.
