## Goal

1. **`crates/ui`.** `Shell::registry()`, `Shell::app()` (read-only);
   `Shell::busy() -> Option<String>` (an open text editor, a drag or
   marquee in progress, an open modal: the wizard, About, Options, a
   close confirmation); handle `UiRequest::AgentControl { enabled }`
   for interactive sources by recording it for the app to read
   (`Shell::take_agent_control_request` or similar); a status-bar line
   showing agent control on, the number of clients and the last remote
   command's label. Tests with `egui_kittest`.
2. **`apps/larrygram/src/agent.rs`.** `ShellHost` implementing
   `larrygram_control::Host` over the shell (`dispatch` through
   `Shell::dispatch` with the invocation as given); the agent-control
   lifecycle (start: runtime directory, token, `Listener::bind` and
   `spawn` with `InboxSender` clones, an executor with
   `attached: true` and the attached policy roots: home plus
   `--allow-dir`; stop: `ListenerHandle::stop`); per frame,
   `Inbox::drain` with at most 8 ops before the shell draws; the waker
   is the egui context's `request_repaint`.
3. **Turning it on.** `--agent-control` starts it at launch; the
   `tools.agent_control` command toggles it and persists the setting;
   a saved `agent_control: true` starts it at the next launch. Off by
   default.
4. **Tests** (no window, `egui_kittest` and a temporary runtime
   directory): with agent control on, a client thread connects with the
   token through the socket, invokes `insert.shape`, and the next frame
   shows the shape; the user's `edit.undo` (as a UI intent) removes it;
   `app.quit` from the client is `Denied`; with a text edit open the
   client gets `Busy`; with agent control off there is no discovery
   file and no socket.

## Master notes

- From the P7-37 review (finding 4): while a new text box is open, the
  shell holds an undo group. If a programmatic command ends that group,
  `Shell::sync_text_box` cancels the editor and the typed text is lost,
  leaving an empty box as an undo step. It cannot happen while the GUI
  hosts no control channel. Once it does, the shell commits the open
  box before running any programmatic intent. Add a test.
