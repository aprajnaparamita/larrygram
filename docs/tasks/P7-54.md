## Why

The user's manual pass of the alpha build (2026-11-05):

1. **Panel Classic offers no way to pick an arbitrary colour.** The
   Fill Color, Line Color and Text Color pickers list theme and
   standard colours; the "More Fill Colors…", "More Line Colors…" and
   "More Text Colors…" rows (`ui-spec/layouts/panel-classic.yaml`)
   do not open a colour chooser.
2. **Panel Modern's Design > Backgrounds gallery is empty.** The
   control lists the `backgrounds` run-time list, which has no
   entries. `Page::background` (`crates/model/src/page.rs`) already
   names a background page.

## Goal

1. **A custom colour, both layouts.** Each "More … Colors…" row opens
   one colour dialog: a hue/saturation/value picker (egui's colour
   picker is fine), a hex field (`#RRGGBB`), OK and Cancel. OK applies
   the colour to the selection through the same command the swatches
   dispatch (`format.set.fill.color`, the line and text colour
   commands) as one undo step, and the colour joins the picker's
   Recent Colors. Cancel changes nothing. Panel Modern's matching
   "More Colors…" rows use the same dialog. Real-input tests in both
   layouts: pick `#3A7F2C` through the hex field for fill, line and
   text, check the cells and the picture; Cancel leaves the cells
   unchanged.
2. **The Backgrounds gallery.** The gallery lists "No Background" and
   a few original backgrounds we design ourselves (for example a solid
   tint, a soft vertical gradient and a light grid; no Visio
   background designs, names or art). Choosing one creates (or reuses)
   a background page holding that design, sets the current page's
   `background` to it, and draws it behind the page's shapes. "No
   Background" clears the link. One undo step each. Background Color
   (the submenu) colours the background page's design. The background
   page and the link save to `.vsdx` and reopen (MS-VSDX: a page with
   `Background='1'` and the foreground page's `BackPage`). If the model
   or the writer lacks a piece of this, add it in this task and say so
   in the Result. Real-input tests in Panel Modern: apply each
   background, check the page's link and the picture, undo, and
   save/reopen.
