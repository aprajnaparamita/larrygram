## Goal

The P7-38 review's items (2026-11-03):

1. **The 3× fallback runs.** Intersect the crop with the image bounds
   (in pixels) before fitting the aspect, and measure the result, not
   the requested rectangle. A crop that can't reach the minimum at 2×
   renders at 3×; one that can't at 3× fails with a clear message. Unit
   test: a crop larger than the frame at 2× falls back to 3×.
2. **No stale PNGs.** `cargo xtask screenshots` deletes
   `<out>/<id>.png` for each selected shot before it runs the tests,
   and passes `--exact` with the full test names. A filter that runs
   zero tests is an error. Test both.
3. **Each shot checks its state.** Every builder asserts, on the
   shell's state, that it reached what its shot describes (editor open
   on the right shape, Edit menu open, page 2 active with its tab menu
   open, wizard on page 2, About shown, a drag in progress). A helper
   that returns `None` (`section_header`, `tab_named`, `menu_rect`,
   `status_rect`) fails the shot instead of carrying on.
4. **The output dir.** The default output is
   `<target dir>/screenshots`, with the target dir from
   `cargo metadata` (as `xtask/src/dist/mod.rs` reads it since R10),
   in both the xtask and the test target.
5. **The shots:**
   - `pages-tabs`: open the menu so all three tabs stay visible (press
     near the second tab's left edge, or move it); assert the third
     tab's rect is outside the menu rect; keep the menu clear of the
     crop edge; crop so the tab strip and menu fill the frame, not the
     Shapes pane.
   - `layout-panel-classic` and every other shot: clear the status
     line after the build, so no build message shows.
   - `text-editing`: pan so the shape sits in the middle of the crop,
     with no off-page grey.
   - `connectors-reroute`: until the connector tasks land, use the
     state after release, with the connectors visibly re-routed,
     instead of an empty drag outline. Say so in the Result.
   - `about-window`: find where the black edge comes from (the harness
     or the dialog backdrop) and fix it in the test target if it is the
     harness; otherwise report it.
6. **Cleanup.** Remove `let _ = middle;` and the unused field, the
   duplicate `rig.settle(2)`, and the crate-wide `allow(dead_code)`
   (allow only where needed, with a reason). Say in the Result which
   steps use dispatch instead of real input (`page.add`, `file.new`).
