## Goal

1. **One page-size resolver (A2).** Page Setup now reads a size
   inherited from a background page, but the canvas, the scene builder
   and zoom-to-fit fall back to Letter, so the dialog and the canvas
   disagree. Put the page-size rule in one place
   (`Document::resolve_page_cell`, with an ADR 0019 amendment, or one
   helper that all four readers call) and delete the private copies.
   Width and height resolve together, from the same sheet.
   **Check the background rung first:** keep it only if MS-VSDX or the
   ShapeSheet reference says a foreground page takes its size from its
   background page. If no allowed source says so, drop the rung (the
   page's own cells, then its style chain, then Letter) and say so in
   the Result. Test with a page whose size comes from its style: the
   dialog, the rendered page and zoom-to-fit all agree.
2. **The checked-state seam sits in Panel Classic (A4).** Move
   `text_toggle_checked` to a layout-neutral module; Panel Modern stops
   calling into `panel_classic`.
3. **Latch precedence (A5).** In `latched`, when the selection gives a
   state for a `format.text.*` control, use only that and ignore the
   display-only set. Test: Bold on shape A, then select plain shape B;
   Bold shows off in both layouts. Also latch Italic, Underline and
   Align Right with real clicks and check each follows the selection
   (review A8).
4. **One label table (A6).** The line-pattern and arrowhead labels live
   in both `format.rs` and `pickers.rs`. Keep one table in `commands`
   and have `pickers` read it. Make `strip_pt` accept any case, like
   `typed_number`.
5. **`percent` only for Zoom (A6).** `draw_combo` adds `percent` to
   every numeric combo; add it only for `shape.draw.zoom`.
